# 競合 → MORU の翻訳ルール(借りる / 捨てる)

TTP(徹底的にパクる)は**構造に対して行い、トーンに対しては行わない**。
ここを分けずに真似ると、勝ちパターンごとブランドを壊す。

## 借りてよいもの

- **構図** — 商品の位置、画角、余白の取り方、被写体の有無
- **フックの型** — 問題提起 / 逆張り / 権威 / 多頭飼い / 疑問形 などの構造
- **訴求の順序** — 問題を書いてから商品に繋ぐ、など
- **束ね方** — 単品で押すか、テーマで特集にするか
- **フォーマットの選択** — 静止画かUGC動画か、スライドショーか
- **尺・アスペクト比** — 9:16 / 4:5 / 1:1 の使い分け

## 捨てるもの

- **トーン全般** — 高彩度、赤黄の煽り、大きな文字焼き込み、glossy HDR広告調
- **期限付き割引訴求** — "Presale pricing ends soon" "20% off" の類。
  MORUは実績のない二重価格・偽の期限を使わない(docs/00)
- **パレット外の色** — docs/01 の9色以外
- **MORUの禁止表現に触れるもの** — 無垢材 / 完全防水 / 丸洗い可能 /
  絶対 / 100% / 残りわずか / 実績のない「人気No.1」
- **猫耳・肉球モチーフ**
- **書けない訴求** — 送料無料(しきい値未確定)、配送の速さ(実態2〜3週間)、
  販売実績(まだ無い)

## そのまま使えるものを見抜く

競合のフックがMORUのブランド思想と一致していることがある。
見つけたら**最優先で使う**。競合は単品の売り文句として使っているものを、
MORUはブランド全体の宣言として使えるので、一貫性で勝てる。

**実例**: Desk Nest Cat Bed の
"Your pet doesn't care what their bed looks like. You do."
= docs/00 v0.2 の感情価値「ペットと近くにいたい。でも自分の生活空間も大切にしたい」

日本語化: 「猫は、ベッドの見た目を気にしない。気にするのは、わたし。」

## 判定に迷ったとき

**docs/01 の写真4原則に照らす**: 明るい自然光 / 抜け感 / 清潔感 / 青アクセント。
競合の見え方がこれと逆(暗い、重い、煽り)なら、構造だけ借りて見え方は作り直す。

**Values⑤「Curated, Not General Store」に照らす**: その表現を使ったとき、
MORUが「売れるものは何でも置く店」に見えないか。

## 実例: UGC動画の翻訳(2026-08)

参照した実物UGC(@shopswithnat / フラワーラウンジ・オリーブ)は、
暗いステインの板張り・斜め天井・古材の床・低い角度の直射光という
**暖色でコントラストの強い空間**だった。

- 借りた: 単一固定テイク / 眠る猫だけ / 一行テキスト / 演出のない生活感 / 12秒の静けさ
- 捨てた: 暖色でムーディーなグレード、暗部の重さ
- 判断: 素材はダーク(ウォールナット #7B5A3C / チャコール #2E2E2E は
  MORUパレット内)にしてよいが、**露出は明るく保つ**。
  「明るさ」と「空間の性格」は両立する

**この翻訳には失敗の経緯がある。** 最初に「明るく・清潔に・余計なものを置かない」を
追求した結果、白い壁に普通のフローリングの"何もない部屋"になり、オーナーから
「おしゃれじゃない」と却下された。空間の魅力は明暗差と素材の経年で決まる。
明るさを守るために性格を消してはいけない。
