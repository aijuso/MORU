# 画像・動画生成の既知の失敗と対処

実際に踏んだものだけを記録する。推測は書かない。

## 1. 特集画像で商品を創作する(重大)

**症状**: 4商品を1枚に収める特集画像で、フラワーバッド テーブルランプが
実物と異なる布製の花ランプとして生成された。実物は充電式の小さなつぼみ形LED。

**原因**: 4商品分の実物写真をリファレンスとして渡していなかった。
リファレンスがない商品はモデルが創作する。

**対処**: 特集画像はリファレンスを**1商品ずつ確実に渡す**か、
各商品を個別に生成して**後から1枚に合成**する。後者のほうが確実。

**これはブランドルール(docs/00 第8章)違反にあたる最も重い失敗。**
商品の形状・サイズ・素材を実物と変える生成は禁止。

## 2. 縦型9:16の画角破綻

**症状**: 下25%が空白のクリーム色で埋まり、実質4:5の画像を上に寄せただけの状態になった。

**対処**: 「画面全体を使った縦構図に。床と壁を下まで続ける」と明示する。
「下部にボタン用の余白」とだけ書くと、余白ではなく空白として処理されることがある。

## 3. 色指定が無視される

**症状**: ivory と指定したのに5枚すべてオリーブグリーンで生成された。

**対処**: 生成後に必ず色を確認する。プロンプトの色指定は強制力が弱い。
リファレンス画像に複数色が写っている場合は
「the references show ivory and olive — use only the IVORY version consistently across all views」
のように**排他的に**書く。

**補足**: この件は失敗だが結果的に有用だった。オリーブは部屋の中で目立つ(フィードで止まる)、
アイボリーはブランドらしい。**A/Bする価値がある**。

## 4. 生成した多視点リファレンスシートは使えない(方式ごと廃止)

**症状**: 実物写真から「多アングルの商品リファレンスシート」を生成したが、
評価10点中5点。参照にない角度(底面など)を創作し、素材感と形状が実物と乖離した。

**原因**: 構造的な問題。参照に写っていない角度はモデルが創作するしかない。
忠実性を求める工程の最初に想像を混入させていた。

**対処**: **この方式は廃止済み。復活させない。**
形状の正は常に実物写真。リファレンスにすべきは「商品の形」ではなく「ブランドの見え方」で、
それは `docs/brand/reference-sheets/` の5枚が担う。

## 5. 空間から性格を消してしまう

**症状**: ロケーション画像で「明るく・清潔に・余計なものを置かない」を追求した結果、
白い壁に普通のフローリングの"何もない部屋"になり、オーナーから却下された。

**原因**: 参照元UGCの魅力は明るさではなく**素材の性格**(暗い板張り・斜め天井・
古材の床・古書の並ぶアンティーク棚・強い斜光)だった。それを全部平坦化していた。

**対処**: 素材はダークにしてよい(ウォールナット #7B5A3C / チャコール #2E2E2E は
パレット内)。**露出だけ明るく保つ。** 空間の魅力は明暗差と経年で決まる。

**併せて**: プロンプトを細かく指定しすぎると「自分の想像が上限」になる。
バリエーションを回して当たりを引きたい場合は、
「20代韓国風一人暮らしの部屋の一角、ミッドセンチュリー、窓際」程度の
**抽象的な指定**にして、9:16 / no people / no pets / no text / 手前の床を空ける
の最低限だけ縛る。当たったプロンプトは必ず控える(抽象プロンプトは再現性が低い)。

## 6. 眠る猫は「動きがない」ため生成が壊れる(動画)

**症状**: 動画生成で被写体が3秒以上ほぼ静止していると、モデルが勝手に動きを発明する。

**対処**: 呼吸・耳のひくつき・まばたき・尻尾の先・植物の揺れ・光の中の埃を、
**秒単位で明示的に配置する**。seedance-scene-director の Gate 9(Stillness)に該当。

## 生成の回し方(クレジット運用)

Higgsfieldは5秒クリップで 480p≈15 / 720p≈23 / 1080p≈45 クレジット。音声を付けると1.5〜2倍。

**まず480p・音声なしで回して構図と動きを確認**し、採用したものだけ高解像度と音声を足す。
眠る猫のような当たり外れの大きい題材は10〜20回転がすのが普通。

**プロンプトを直すのは「毎回同じ壊れ方をするとき」だけ。**
毎回違う壊れ方なら回し直すほうが早い。
