# 見出し・本文・説明の書き方(Meta動的クリエイティブ)

Metaは見出し5・メインテキスト5・説明5を登録でき、**組み合わせを自動でテストする**。

## 設計の原則

**5つを同じことの言い換えにしない。** 同じ角度で5本作ると、
どれが当たっても「何が効いたか」が分からず学習がゼロになる。角度を変える:
逆張り / インテリア問題 / 共生 / 機能 / 商品そのもの。

**組み合わせはランダムに入れ替わる。** 見出しと本文が特定のペア前提だと事故る。
それぞれ単独で成立し、どう組み合わさっても矛盾しないように書く。

## 3フィールドの役割分担

| | 役割 | 注意 |
|---|---|---|
| メインテキスト | 共感で引き込む | **冒頭125字ほどで折りたたまれる。1行目に結論** |
| 見出し | 一番の売り文句 | ここに勝負をかける |
| 説明 | 事実で補強 | **Instagramでは表示されないことが多い**。重要情報を入れない。空欄にもしない |

説明は感情に訴える言葉より**短い事実**が向く。どの見出しの下に来ても成立するものにする。

## 書いてはいけないこと(MORU固有)

- **送料無料** — しきい値が未確定(表示¥15,000 / ストア設定¥7,700 の不整合が未解決)
- **配送の速さ** — 実態は2〜3週間。「すぐ届く」系は使えない
- **販売実績** — 「累計○個」「人気No.1」等。実績がまだないので虚偽になる
- **価格** — sale タグ運用中のため広告文と実価格がズレるリスク
- docs/01 の禁止表現全般(絶対 / 100% / 残りわずか / 無垢材 など)

## 実例(フラワーラウンジ・2026-08)

見出し5種 — 角度が全部違う:
```
1. 猫は見た目を気にしない。気にするのは、わたし。   ← 逆張り(本命)
2. ペット用品に見えない、猫のベッド。               ← インテリア問題
3. 追い出さずに、となりに居場所を。                 ← 共生
4. 置きっぱなしにできる、猫のラウンジ。             ← 機能
5. 花のかたちで、猫がまるくなる。                   ← 商品そのもの
```

説明5種 — 短い事実:
```
アイボリー / オリーブグリーンの2色
猫・小型犬のためのラウンジソファ
花びら型クッション × 木製フレーム
床から浮かせた、家具のようなかたち
MORU フラワーシリーズ
```

## 配信後の使い方

1〜2週間後、Metaの管理画面で見出しごと・テキストごとの成果が見られる。
**負けている組み合わせを切って、勝った角度で次の5本を作る。**
これがこのフォーマットの本来の使い方で、作りっぱなしにしない。

## 予算の注意

見出し5×本文5を回すとMetaは学習のために配信を広げる。
**在庫が少ない商品では日予算を絞る**(1日2,000〜3,000円程度)。
当たった瞬間に在庫が飛ぶ。
