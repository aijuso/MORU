# Winning Hunter Research(ブランド非依存の商品リサーチ標準)

**思いつきで商品を選ばない。市場で実際に売れている証拠を積んでから選ぶ。**

このスキルは「何を売るか」を決める標準手順。どのブランドでも同じ6フェーズで回す。
ブランド固有の判断(世界観適合・価格ルール)は §6 のアダプタに切り出してあり、
スキル本体は書き換えずに新ブランドへ持ち出せる。

出典: オーナーコンサル資料 Phase 1(`docs/consulting/playbook_digest_20260831.md`)+
MORU での実運用の学び(`ops/research/`)を一般化したもの。

## 0. 接続と残量の確認(毎回最初にやる)

1. Winning Hunter MCP が接続されているか確認する(ツール一覧に `winninghunter` 系があるか)。
   無ければ `ops/research/winning_hunter_setup.md` の手順をオーナーに案内して**止まる**。
   AdWhispr での代替可否は目的次第(広告分析は可 / TikTok Shop・Shopifyストア追跡は不可)
2. **クレジット残量を最初に確認する**(ツール呼び出し1回=1クレジット消費)。
   残量に対してクエリ計画を立ててから叩く。**同じ検索を条件を変えて連打しない** —
   1回のクエリで広く取り、絞り込みはローカルで行う
3. 取得したデータには**必ず取得日を付けて保存**する(保存先は §7)

## 1. 条件設計 — 「売れている」の定義を先に固定する

検索を始める前に、以下のテンプレートを埋めて条件を宣言する。
埋めずに検索を始めない(後から条件を動かすと「証拠」が「後付け」になる)。

| 条件 | 既定値(根拠が無ければこれを使う) | 今回の値 |
|---|---|---|
| 出稿継続日数 | **14日以上**(理想30日+)。継続出稿=広告費を回収できている推定 | |
| 同一商品のアクティブ広告数 | 3本以上 | |
| 類似商品を扱う競合ショップ数 | **2店舗以上**(=需要の裏付け。1店舗だけなら属人バズの疑い) | |
| エンゲージメント | 直近30日で伸びている(絶対値より傾き) | |
| 価格帯 | ブランドアダプタの利益ラインから逆算(§5) | |
| カテゴリ / 除外カテゴリ | 規制リスクの高いもの(§4)は最初から除外 | |
| 対象市場 | 検索対象の国(既定: US / 展開先: 日本) | |

## 2. ロングリスト — 10〜20商品を機械的に集める

- Meta広告検索・TikTok Shop・トレンド機能を使い、§1の条件に合う商品を **10〜20件**列挙する
- この段階では**絞り込まない・評価しない**。条件に合うものを全部拾う
- 各商品に記録する事実: 商品名 / 販売ショップURL / 価格 / 広告開始日(=継続日数の起点) /
  アクティブ広告数 / エンゲージメント指標 / 取得日

## 3. 深掘り — 需要の証拠を商品ごとに積む

ロングリストの各商品について:

- **広告の継続性**: 一時的バズか、再現性のある出稿か(出稿の時系列)
- **競合の厚み**: 同じ商品を売るショップが何店あるか。**多すぎ(5店+)は消耗戦の兆候**、
  ゼロは需要未実証。2〜4店が甘い帯
- **ショップ全体**: 単品ストアか総合か。単品で成立しているなら商品の力が強い証拠
- **完売シグナル**: 対象ショップの `/products.json` で Sold Out を確認できる場合、
  完売は「宣伝している」ではなく「実際に売れた」証拠として最上位に扱う(MORU 実運用の学び)
- **推定売上・出稿規模**: 取れる範囲で記録(推定値は推定と明記)

## 4. 日本展開可否 — 1つでも赤なら不採用か専門家行き

- [ ] **法規制**: 電気(PSE)・電池・磁石・化粧品・健康食品・食品接触・医療的効能(薬機法)
- [ ] **知財**: 意匠権・商標権の侵害品でないか(仕入れ元照合時にブランド刻印・キャラ類似を確認)
- [ ] **輸送**: リチウム電池等の輸送制限 / サイズ・重量が送料区分に収まるか
- [ ] **季節性・文化**: 日本の住環境・季節に合うか。売れ筋の理由が日本に存在しない文化要因でないか

**Claude の判断は一次スクリーニング。最終判断は専門家(弁護士・税理士・通関業者)へ。**

## 5. 利益成立性 — 売れていても儲からなければ捨てる

- 仕入れ値(1688 / CKB 等)を照合し、**着地原価(商品原価+国際送料+手数料)**を出す
- 販売可能価格 = 市場の実売帯(§3で観測した競合価格)と、
  ブランドアダプタの値付けルール(例: MORU は着地原価×3.0)の両方に収まるか
- **CPA許容余地**: 限界利益(販売価格 − 着地原価 − 決済手数料 − 返金引当)が
  想定CPAを十分上回るか。目安が無いブランドでは限界利益の50%を仮のCPA上限に置く
- 送料実測が無い段階の送料は**概算と明記**する(概算を実測のように扱わない — MORU の反省点)

## 6. ブランドアダプタ — 世界観適合は各ブランドが持つ

ここまでの §1〜5 は全ブランド共通。最後に**そのブランド固有の rubric** で適合を評価する:

| ブランド | アダプタ(評価基準の正) |
|---|---|
| MORU LIVING | `ops/research/rubric.md`(問題解決力 / 世界観適合 / セット候補 / 色展開数) |
| (新ブランド) | 立ち上げ時に `ops/research/rubric.md` を雛形に新規作成する |

アダプタが未整備の新ブランドでは、最低限「誰の・どんな問題を・どう解決するか」を
一文で書けるかだけを判定に使う(書けない商品は世界観以前に売り方が作れない)。

## 7. 絞り込みと記録

- **本命は1〜3商品**に絞る。落とした商品も理由ごと記録する(次回のリサーチで再評価できるように)
- 保存先: そのブランドの研究ディレクトリ(MORU: `ops/research/` + 商品リサーチDBシート)。
  ファイル名に取得日を入れる(例: `_wh_research_YYYYMMDD.md`)
- 記録に含める: §1の条件表(埋めた状態) / ロングリスト / 深掘り結果 / 可否チェック結果 /
  利益試算 / 本命と落選理由 / **消費クレジット数**
- 本命が決まったら: 商品登録はブランドのワークフロー
  (MORU: `.claude/skills/product-registration/`)へ、広告設計は `ad-benchmark-creative` へ渡す

## 禁止事項(全ブランド共通)

- 海外ショップの画像・文章の無断転用(著作権・意匠権)
- 偽レビュー・偽割引・偽在庫・偽カウントダウンを前提とした商品選定
  (「煽りが無いと売れない商品」はその時点で不採用)
- 検証していない品質表現(完全防水・100%安全 等)を前提にした訴求設計
- クレジットを消費する再検索の連打(1クエリ広く取り→ローカルで絞る)
