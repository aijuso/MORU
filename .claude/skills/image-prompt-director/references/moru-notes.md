# MORU 運用ノート(image-prompt-director 用・原本非改変の追記)

> 原本(SKILL.md / templates.md / lexicon.md)はオーナーの汎用スキルの**完全コピー**。
> このファイルだけが MORU リポジトリ固有の追記。原本の内容と矛盾したら、
> MORU の商品・ブランドに関する事項は**このノートと docs/00〜01 が勝つ**。

## ブランド制約(必ず反映)

- 写真の4原則: **明るい自然光 / 抜け感 / 清潔感 / 青アクセント**(docs/01 §3)。
  原本のデフォルト(naturalistic cinematic)より**明るく・軽く**寄せる
- パレットは docs/01 §2 の9色。**差し色は1画面1〜2色まで**。
  **ただし生成画像のアクセントを「ブルー×テラコッタ」に固定しない(D-070)。**
  カラフル・ポップに、商品ごとに色味を変えてよい。守るのは色そのものではなく「1〜2色に絞る」という使い方
- サムネイルは**白抜き禁止・明るい生活シーンの中の商品**(シート03)
- アングルは `docs/brand/reference-sheets/04_category_angles.png` の18分類に従う
- 禁止: 猫耳・肉球モチーフ / 高彩度ペットショップ風 / glossy HDR ad look

## 参照画像は必ず2種類渡す(D-068)

| 参照 | ファイル |
|---|---|
| ① ブランド基準 | `docs/brand/reference-sheets/0X_*.png`(該当シート + `01_brand_visual.png`) |
| ② 形状の正 | その商品の **Shopify 登録済み商品画像** |

**プロンプト冒頭で「これは MORU のブランドデザイン基準である」と明示して ① を添える。**
テキストで世界観を説明して済ませない。**シートを実際に渡す。**

枚数の目安(D-071): サムネ **1枚(必須)** / 商品画像 **5枚程度** / 説明画像 **3枚程度**。
**バリアントが複数ある商品は、各バリアントに合わせた画像を作れるとベスト。**

## 商品が写る画像の鉄則(商品登録スキルと同じ)

- **商品の形状・サイズ・素材を実物と変える生成は禁止。** 商品はリファレンス画像で固定し、
  プロンプト冒頭に reproduce faithfully / do not redesign 系のロックを入れる
- 生成でよいのは背景・部屋・小物・雰囲気。**「切り抜いて背景だけ差し替えろ」という工程指示は書かない(D-069)。**
  商品画像を参照として渡せば製品は再現される。書くのは工程ではなく**欲しい絵**
- 猫の沈み込み・スケール感を誤認させる合成をしない(docs/00 第8章)

## Higgsfield MCP で実行する場合

- 画像URLの取り込み: `media_import_url` → 返る media_id を `medias[].value` に渡す
- モデルの目安: 商品+背景の編集系は Nano Banana 系 / 4K・文字は nano_banana_pro /
  雰囲気カットは soul 系。パラメータは `models_explore` で確認してから使う
- 生成結果の採否は**必ずオーナーの形状一致チェック**(人間ゲート)を通す

## 実績のあるプロンプト構造(このプロジェクトでの前例)

- 商品ヒーローショット: Object/Product テンプレート + 冒頭に reference-fidelity ロック +
  背景を Warm Ivory 系スタジオ指定(2026-08 フラワーラウンジで使用)
- 多視点リファレンスシート生成は**廃止済み**(形状創作の問題)。復活させない
