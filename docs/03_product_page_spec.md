# 03. 商品ページ仕様 — MORU LIVING(フラワーラウンジ基準)

> フラワーラウンジ(最初のHero商品)で最適な形を作り、それを全商品の標準テンプレートにする。
> 表現・配送・法務の規定は `docs/00_brand_master.md` 第5章・第11章・第12章が正。

## First View(スクロールなしで見えるべきもの)

左2/3: 商品ギャラリー
- メイン大画像+サムネイル列(単体写真/使用写真/部屋の引き画/ディテール)
- カラーバリアント切替でギャラリーが該当色に切り替わる

右1/3(上から):
1. 商品名(例: `MORU フラワーラウンジ`)+ 短い読み仮名的サブ(例: `花びら型の猫用ベッド・ペットソファ`)
2. 価格(税込表記)
3. 世界観コピー2行(例: `猫が寝転ぶと、部屋が完成する。` 系。docs/00の推奨コピーから)
4. **カラースウォッチ**: 丸いスウォッチ(アイボリー/オリーブ)。選択色に画像・在庫が追従。バリアント画像がない商品はスウォッチ非表示のフォールバック
5. サイズ表記(例: `約 幅56 × 高さ32cm / 床から座面下 約11cm`)
6. カートボタン(Charcoal・full width)
7. **お届け目安ボックス**(Soft Cream背景・スクロール前に必ず見える):
   `お届け目安:ご注文から約2〜3週間`
   `ご注文後、海外パートナーより商品を手配し、検品後に発送いたします。`
   ※在庫・国際輸送・通関等により4週間以上かかる場合がある旨は詳細セクションに明記

## 商品ページ下部(順序)

1. **カラー別スタイリング**: `アイボリーの部屋` / `オリーブの部屋` の2分割ライフスタイル写真(広告アングルEと共通クリエイティブ)
2. **特徴 4〜5点**(アイコン+短文): 花形デザイン / 高密度中綿 / 通気性のある生地 / 床から約11cmの脚付き / クロス構造・耐荷重約18kg
3. **使用シーン**: リビング / ベッドサイド / 窓辺 / ソファ横
4. **サイズ図**: 寸法を図解(幅56cm・高さ32cm・床下11cm)
5. **仕様詳細(アコーディオン)**: 素材 / セット内容 / 組み立て / お手入れ(未確認事項は書かない)
6. **配送について(アコーディオンだが見出し常時視認)**: 2〜3週間、場合により4週間以上 / 土日祝は営業日に含めない / 到着日を確約しない
7. **海外製品の個体差について**: 木目・色合いの違い / 積層部分の見え方 / 軽微な誤差・擦れ / パッケージの傷(docs/00 第12章の文言)
8. **キャンセル・返品**: 手配開始後のお客様都合キャンセル原則不可(手配前は対応できる場合あり)/ 不良・誤配送は到着後7日以内連絡で交換または返金
9. **レビュー**: 実購入者のみ。発売前はセクション非表示(偽レビュー禁止)
10. **関連商品**: `あわせて楽しむアイテム`(同じ部屋に置ける商品を優先)

## 表現ルール(実装時にコピーへ反映・違反禁止)

- 「無垢材」と書かない(木質素材・積層構造を含む)
- 「防水」「丸洗い可能」「洗濯機対応」を書かない(未確認)
- 「毛羽が出にくい生地」程度に留める(Shed Resistantの訳)
- 耐荷重は「約18kg」(仕入先公称40lbからの換算である旨は社内メモ)
- 「即納」「国内発送」と誤認させない
- 「絶対」「100%」「どんな猫にも」等の断定禁止
