# 01. ブランドガイドライン(実装用要約)— MORU LIVING

> 上位文書は `docs/00_brand_master.md`。本書はテーマ実装で日常的に参照する要約。矛盾したら00が正。

## ブランド一言定義

> **猫用品から始まる、人とペットのトレンド・インテリアブランド。**
> 売るのは商品ではなく「猫がいる景色まで好きになれる部屋」。

- タグライン: **暮らしを、好きな景色に。**
- 最初のHero商品: **MORU フラワーラウンジ**(花びら型クッション+木製フレームの猫用ベッド、アイボリー/オリーブ)
- 商品コピー: **猫が寝転ぶと、部屋が完成する。**

## トーン(旧ブランドからの最重要変更)

旧MORU=「大人の雑誌」(硬さ8/10)→ 新MORU=「**陽当たりのいい部屋の雑誌**」(硬さ6/10)。

- 残すもの: セリフ体見出し、広い余白、編集(キュレーション)感、Mid-Centuryの背骨
- 柔らかくするもの: 配色(暗いウォールナット→明るいバーチ)、コピー(言い切りすぎない・やさしいが幼くない)、写真(猫と生活感が写る)
- **絶対にならないもの**: かわいいペットショップ、丸文字・ポップ文字、猫柄/肉球柄依存、Francfranc的な軽さ、子供っぽい原色ポップ

## Mid-Century要素の扱い(統合方針)

Mid-Centuryは**色ではなく「かたちと素材」で残す**:
- 有機的な曲線(花形、マッシュルームランプ、丸テーブル、丸みのある椅子)
- Chrome / オパールガラス / スモークガラスの小物を少量
- アクセントカラー(Olive / Terracotta / Burgundy)
- ダークウォールナットの重厚さには寄せない(デザインバランス: Warm/Natural 40% / Korean 25% / Mid-Century 25% / Pop 10%)

## ロゴ

- `docs/brand/logo_terracotta.png` — テラコッタ色のレトロなラウンドセリフのワードマーク「MORU」

## タイポグラフィ

- 見出し: 丸みと編集感のあるセリフ体(Cormorant Garamond / DM Serif Display / Playfair Display 系)。ロゴの雰囲気に寄せる
- 日本語本文/UI: Noto Sans JP / Zen Kaku Gothic New 系
- 大見出しは余白を広く。日本語本文は可読性優先。筆記体の多用禁止。丸文字・ポップ文字禁止
- SALE表示だけが強くなる量販店的デザインを避ける

## 写真・画像トーン

- 自然光の明るく暖かい部屋。猫が実際に使っている姿+部屋全体が分かる引き画
- 木・布・ラグ・植物を組み合わせ、「猫のかわいさ」より「部屋の完成度」を見せる
- 避ける: 白背景のみ構成 / 中国EC文字入り画像の流用 / 高彩度ペットショップ風 / 実物と異なるAI形状 / 実際より大きく見せる合成
- 商品一覧の1枚目は Warm Ivory系背景・暖かい光・余白・文字なしで統一

## コピー・文言(実装に直結)

- 文体: 短く具体的。です・ます基調。感情(未来)と仕様(証拠)を分けて書く
- 推奨コピーは docs/00 第11章のリストから使用
- **避けるコピー(UIに実装しない)**: 「絶対に使ってくれる」「100%安全」「完全防水」「一生使える」「残りわずか(事実でない場合)」「本日限定(毎日更新)」等
- 禁止実装: 偽カウントダウン、偽在庫表示、恒常的な二重価格(取り消し線)表示

## SALEの扱い

- セール/クーポン訴求は可(Announcement Bar等、控えめに)
- 禁止: バッジ乱用、点滅、カウントダウン、実績のない通常価格からの割引表示
