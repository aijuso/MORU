## §1. ブランド一言定義(v0.2)

> **Pet-first, Interior-always.**
> 「一緒に暮らす」を、もっと美しく。

- 売るのは商品ではなく「**ペットがいる景色まで好きになれる部屋**」
- **ペット用品専門店にならない。** 猫家具は入口
- 拡張の順序: Pet Living → Playful Living → New Retro Interior
- 現行の Hero 商品: **MORU フラワーラウンジ**(花びら型クッション+木製フレームの猫用ベッド)

### コピーの源泉

すべてのコピーは docs/00 v0.2 追補 §0-5 の Emotional 層の一文から引く:

> **「ペットと近くにいたい。でも自分の生活空間も大切にしたい」**

機能訴求だけの見出しに落とさない。

## §3. トーン(v0.2)

### 写真の4原則(シート01)

| 原則 | 意味 |
|---|---|
| **明るい自然光** | 窓光ベース。硬い影・色かぶりを作らない |
| **抜け感** | 詰め込まない。視線が奥へ抜ける。壁の枝葉の影を活かす |
| **清潔感** | 白〜ベージュの面積を広く。彩度を上げすぎない |
| **青アクセント** | MORUブルーを画面のどこかに必ず1点置く |

### Playful の出し方(重要)

**原色の乱舞ではない。**

> 差し色 1〜2色 + **遊び心のある形**(花形・ウェーブ・パンプキン型・マッシュルーム型)

**ベースは常に明るく清潔な生活シーン。** 形で遊び、色では暴れない。

### タイポグラフィ

- 日本語本文/UI: Noto Sans JP / Zen Kaku Gothic New 系
- 見出し: **ゴシック体が基本**(docs/07 §3 の確定事項 — 「新着アイテム」「部屋で見る」は明朝ではない)。
  ロゴまわりや記事タイトルなど限定的にセリフ体を使ってよい
- 筆記体の多用禁止。**丸文字・ポップ文字禁止**
- **フォントの最終決定は PENDING**(§8)

### 絶対にならないもの

かわいいペットショップ / 丸文字・ポップ文字 / 猫柄・肉球柄依存 / 子供っぽい原色ポップ /
SALE表示だけが強い量販店デザイン。

## §4. SALE・バッジの扱い(**v0.1 から明示的に方針転換**)

### 解禁したもの

- **番号付きベストセラー**(1〜5位のランキングバッジ)
- **NEWバッジ**
- **セールバナー**
- **組み合わせ割**(セット購入割引)

### 引き続き禁止

- **偽カウントダウン**(実際に終わらない締切)
- **偽在庫**(事実でない「残りわずか」)
- **実績なき二重価格**(販売実績のない通常価格からの取り消し線表示)
- バッジの乱用・点滅

**判定基準は一つ: その表示が事実か。** 事実なら出してよい。事実でないなら実装しない。

### 現時点の運用上の注意

- ベストセラーは**販売実績が出るまで順位を出さない。**「人気アイテム」等、実績を偽らない表記にする(docs/02 §5)
- 送料無料しきい値・お届け目安は**ストアの実設定と一致させる**。乖離は虚偽表示

## §6. 画像ルール(シート02 / 03 / 04 / 05 の要約)

**詳細は各シートの .md を読むこと。ここは実装時の早見。**

### サムネイル(一覧・カテゴリ用)— シート03

**白抜きではなく「明るい生活シーンの中の商品」が正。**

- 背景は整える(白壁・明るい木・植物程度に絞る)
- 差し色1〜2色 / 商品が主役 / 余白を確保
- **全商品で世界観を統一**(一覧に並べたとき同じ部屋の写真に見えること)

### 商品画像(メイン)— シート02

**メイン(生活シーン)+ ディテール + 素材感 + 使用シーン + サイズ感** の5点構成。

- 自然光 / 商品が主役 / 背景は整える / 差し色を活かす / **ペットは自然に写す** / 余白を残す

### 説明画像 — シート05

**① 素材・質感 / ② ディテール / ③ サイズ・寸法 / ④ 使用シーン** の4点セット。

- 文字・図はシンプル / 余白を活かす / トーン統一 / 読みやすく

### アングル — シート04

**18分類ごとの推奨アングル表に従う。** 迷ったら正面や45度。
商品単体だけでなく生活空間での使用イメージを大切にする。

### 制作の鉄則(全タイプ共通)

- **形状の正は常に実物写真。** 形状・サイズを変える生成をしない
- フル生成より **実物切り抜き + 背景差し替え** を優先。商品ピクセルは極力触らない
- 中国EC由来の文字入り画像をそのまま使わない
- 実際より大きく見せる合成をしない

## §7. コピー・文言

- 文体: 短く具体的。です・ます基調。**感情(未来)と仕様(証拠)を分けて書く**
- UIの基本言語は日本語。文言は `locales/ja.default.json` の翻訳キーで管理(**Liquid直書き禁止**)
- **避けるコピー(実装しない)**: 「絶対に使ってくれる」「100%安全」「完全防水」「一生使える」
  「無垢材」「丸洗い可能」(未確認)「残りわずか(事実でない場合)」「本日限定(毎日更新)」
  「最短翌日お届け」(**海外取り寄せモデルでは使用不可**)
- 「ドロップシッピング」を顧客向けに出さない。**配送目安は隠さず明示する**
