## 1. 経済ロジック(口述より)— なぜ利益1万円/個か

- **構造**: 配信初期は狭いオーディエンスで CPA が低い → 予算を上げると同じ人への表示が増える
  (フリークエンシー上昇)→ ターゲットを広げざるを得ない → **CPA は運用が続くほど上がる**
- **利益1万円の意味**: 単品の限界利益が大きいほど、CPA 高騰に耐えて**長く売り続けられる**。
  利益1万円なら CPA ¥10,000 が損益分岐 = 耐久力そのもの
- 計算例(口述のまま): 日予算¥20,000・CPA¥4,000 → 5件 → (10,000−4,000)×5 = **日次利益¥30,000**
- アンカー(最低ライン)も先に決める: 「最低利益¥3,000なら CPA 上限は…」と逆算で設計する

## 2. 高く売る方法 = 「切り口(価値の掛け算)」(口述より)

- 原価¥500〜1,000 の商品を ¥10,000〜15,000 で売る鍵は **商品を見せる切り口を複数持つこと**
- 切り口の型:
  - **比較(アンカリング)**: エルメスの Apple Watch バンド¥210,000 vs 似た品¥15,000 /
    GU・ユニクロと同じ箇所を見せて差を示す
  - **高見え**: 最も分かりやすい切り口。「高く見える時計ケース¥20,000」に違和感がない状態
  - **コンプレックス解決**: 「小顔に見せるサングラス」
  - **用途の再定義**: 「走れるサンダル」(ウェルネス文脈で1日3個×利益1万円=月90万の実例)
- **切り口を複数掛け算できる商品ほど高くできる。** 切り口が思いつかない商品
  (例: 地味なレザーバンド)は高く売るのが難しい=マイニング段階で避ける
- ⚠️ **MORU/日本での適用条件(こちらの原則)**: 切り口=ポジショニングは可。
  ただし**事実でない性能主張は不可**(CLAUDE.md ルール6・8、薬機法・景表法。PDF自身も薬機法に言及)。
  「走れる」「小顔に見える」の類は、実際にそう使えること・観察可能なことが条件

## 3. マイニングの基本思想(PDF PART1)

- マイニング = 「商品を探す」ではなく**「実証済みの需要を見つけ、競合より上手く実行する」**。
  見るのは商品でなく**お金の流れ**(誰が・どれだけの期間・何本のクリエイティブで広告しているか)
- 捨てる思い込み: ①誰も売っていない商品を探す(市場検証は資本のある企業の仕事)
  ②自分の好みで選ぶ ③商品さえあれば売れる(**商品は結果の30%。オファー/クリエイティブ/ページが70%**)
- 目標は1商品でなく**仕組み**: **週20商品を発掘 → テスト価値のある2つに絞る**サイクル

## 4. ヒット商品の6特徴(PDF PART2)= 判定チェックリストの原型

| # | 特徴 | 判定テスト |
|---|---|---|
| 1 | **ターゲットが広い** | ①「〜が好きな人」と言わずに説明できるか ②**同じ商品で3つの異なる訴求軸を書けるか(最重要)**。日本の広い層: 主婦30-55 / 高齢者・介護 / **ペット飼育者** / 通勤サラリーマン / 育児中の母 |
| 2 | **痛みを解決する** | 痛みのヒエラルキー: 身体的 > 経済的 > 社会的な恥 > 美容 > 欲求(上ほど説得が楽)。日本特有の構造的な悩み: 肩こり腰痛 / 収納・省スペース / 湿気カビ(5-7月) / 猛暑(6-9月) / 冷え(11-2月) / 花粉(2-4月) / 掃除 / 介護。**日本人が思わず口にする一文で言語化できなければカテゴリを見つけただけ** |
| 3 | **ワオ要素** | **無音・3秒テスト**: 音声字幕なしで3秒以内に何かが伝わり「いいな」と思えるか。4種: 見た目の変化 / 満足感のある動作(ASMR的) / 不釣り合いな結果 / 意外な形状。地味だが有用な商品はクリエイティブコスト3倍 → 初心者は避ける |
| 4 | **知覚価値 > 価格** | 知覚価値 = 悩みの大きさ + 効果への信頼 + 積み増し要素 − 手間とリスク。6レバー: ①アンカリング ②価格の前に悩みを掘る ③積み増し(特典/保証/日本語サポート/包装/送料無料) ④証拠(日本人の名前・写真のレビュー/数字) ⑤リスク軽減(返金保証/特商法表記/国内決済/**配送日数を正直に**) ⑥高見えする見せ方。**「価値を構築する余地がある商品」を探す**(コモディティは却下=Temuと価格競争は自滅) |
| 5 | **競合が伸びている** | 伸びのサイン: **出稿21日以上継続** / 同一商品で複数クリエイティブ / 日本で複数の広告主 / コメント増 / 直近30-60日のレビュー蓄積 / 楽天・Amazonランキング上昇。**飽和度カーブ(日本の広告主数): 0人=リスク大 / 1〜3人=理想 / 4〜9人=独自の切り口が必要 / 10人以上=手遅れ**。黄金律: **USで伸びていて日本の広告主が0〜2人**(日米の時差3〜6ヶ月が構造的チャンス) |
| 6 | **素材が揃っている** | 5項目中3つ: 動いている動画 / UGC / 透かしなし白背景写真 / 自分で購入して撮影可能 / ビフォーアフター実演。**写真2枚+中国語ロゴ焼き込み+動画なし=却下**(自分で撮る前提でのみ採用)。素材源: AliExpress / 1688 / TikTok / Amazon.co.jp / 広告ライブラリ(構成参考のみ・コピーNG)/ サプライヤーに素材パック依頼 |
