## §1. 概算方式

### 送料概算(サイズ区分)

| 区分 | 目安 | 対象の例 | 送料概算 |
|---|---|---|---|
| **小物** | 〜1kg | 雑貨・テキスタイル小物(クッションカバー・ブランケット・オブジェ・時計・コースター) | **¥800** |
| **中型** | 1〜3kg | ランプ・チェア・ペットベッド類 | **¥1,750** |
| **大型** | 3kg〜 | テーブル・サイドボード・ソファ・キャットタワー | **¥3,500** |

### 計算

```
着地原価概算 = 仕入れ値(Shopify の現 price 欄) + 送料概算
通常価格     = 着地原価概算 × 3.0 を ¥X,980 / ¥X,480 に切り上げ丸め
検算         = クーポン20%適用後も 着地原価概算 × 2.4 を下回らないこと
```

**丸めは切り上げのみ。** `X,480` と `X,980` のうち、×3.0 の値**以上**でいちばん近いほうを採る。

### 検証済みの実例(フラワーラウンジ)

| 項目 | 値 |
|---|---|
| 仕入れ値 | ¥1,381 |
| サイズ区分 | 中型 → ¥1,750 |
| 着地原価概算 | **¥3,131**(CKB の実見積と一致) |
| ×3.0 | ¥9,393 |
| 丸め後の通常価格 | **¥9,980** |
| 20%OFF後 | ¥7,984 |
| 着地原価に対する倍率 | ×2.55 ≧ 2.4 ✓ |

## §2. 低単価小物の扱い

- **仕入れ値 ¥500未満の小物は単品価格を付けない。** `tier-aov` として同梱・クロスセル前提で扱う
- どうしても単品販売する場合の**下限価格は ¥1,480**
  (それ未満だと送料 ¥800 を吸収できず、限界利益がほぼ消える)

## §3. 割引の扱い

- **割引はクーポン方式のみ。**
- **取り消し線の二重価格表示は禁止。** 販売実績のない「通常価格」との比較は
  実績なき比較価格にあたる(docs/01 §4 / CLAUDE.md 絶対ルール6)
- クーポンは**期間を明示する。** 終わらない「発売記念」を出し続けない
- ~~現行: フラワーラウンジ 通常 ¥9,980 / 発売記念クーポン **20%OFF(期間明示)** → 実売 ¥7,984~~

  設計として書かれたが**実装されていない。** 上の数字は「もし実施したら」の試算として読むこと

## §4. 広告の採算(Meta / TikTok Ads)

**広告チャネルは Meta と TikTok Ads の2つのみ。TikTok Shop アフィリエイトは行わない**(D-033)。

### 限界利益

```
限界利益 = 販売価格(税込) − 着地原価概算 − 決済手数料 − 想定返品コスト
```

※ 決済手数料・返品率の実測が無い間は、**決済手数料 3.6%** を仮置きし、返品コストは 0 とする。
   実測が出たら本書を更新する(仮置きであることを価格判断のたびに明示する)。

### 損益分岐ROAS

```
損益分岐ROAS = 販売価格 ÷ 限界利益
```

これを下回る ROAS で回すと、売れば売るほど赤字になる。

### CPA上限

```
CPA上限 = 限界利益 × 0.70
```

**限界利益の70%を超える顧客獲得単価では回さない。** 残り30%が固定費・返品・在庫リスクの吸収分。

### フラワーラウンジでの試算(決済手数料3.6%仮置き)

| 項目 | 通常価格 | クーポン20%OFF |
|---|---|---|
| 販売価格 | ¥9,980 | ¥7,984 |
| 着地原価概算 | ¥3,131 | ¥3,131 |
| 決済手数料(3.6%) | ¥359 | ¥287 |
| **限界利益** | **¥6,490** | **¥4,566** |
| 損益分岐ROAS | 1.54 | 1.75 |
| **CPA上限** | **¥4,543** | **¥3,196** |

~~**クーポンを併用する前提なら CPA上限は ¥3,196 で見る。** 通常価格側の数字で広告を回さない。~~

⚠️ **2026-08-24 実査による訂正: 併用するクーポンが存在しない。**
現状で広告を回すなら、見るべきは**通常価格側の CPA上限 ¥4,543** のほう。
ただし決済手数料 3.6% は**依然として仮置き**で、返品コストは 0 のまま(未確認)。
**数量割引を入れる場合は、10%OFF / 15%OFF それぞれの CPA上限を出し直す**
(商品別の試算は `ops/products/_price_audit_20260824.md` §3)。

## §5. 運用

| 項目 | 誰が | いつ |
|---|---|---|
| 概算方式による初期値付け | Claude | 商品登録時(本書の式で機械的に) |
| サイズ区分の判定 | Claude | 商品情報から機械判定。**迷ったものは一覧にしてオーナー確認** |
| **本値付け(競合突き合わせ)** | **オーナー** | **販売開始後に適宜** |
| 決済手数料・返品率の実測反映 | オーナー → Claude | 実績が出たら本書を更新 |

### 商品ごとの記録

価格を設定したら:

1. `needs-pricing` タグを**外す**
2. `ops/products/{分類}-{商品}/product.md` に記録する:
   **仕入れ値 / サイズ区分 / 着地原価概算 / 通常価格**
