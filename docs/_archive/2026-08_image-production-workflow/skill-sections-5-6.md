### 5. 画像棚卸し(ルーブリック)

取り込んだ全画像を**3軸**で評価し、表にして `product.md` に残す。

| 軸 | 評価内容 |
|---|---|
| ① **文字の有無と量** | 文字なし / 少量(型番等)/ 大量(中国語の説明パネル) |
| ② **写真の役割** | メイン / ディテール / 素材感 / 使用シーン / サイズ感 / 用途不明 |
| ③ **ブランド適合** | シート01の4原則(明るい自然光・抜け感・清潔感・青アクセント)に合うか |

**重複は役割ごとに最良1枚だけ残す。** 同じ役割の画像を何枚も出さない。

棚卸しの結果、各画像は次の3タイプのいずれかに振り分けられる。

### 6. 3タイプ別パイプライン

#### 生成の共通ルール(全タイプ・D-068 / D-069 / D-070)

**参照画像を2種類とも必ず渡す。テキストで説明して済ませない。**

| 参照 | ファイル | 役割 |
|---|---|---|
| ① **ブランド基準** | `docs/brand/reference-sheets/0X_*.png`(タイプ別に該当シート + 01) | トーン・光・構図・世界観 |
| ② **形状の正** | その商品の **Shopify 登録済み商品画像** | 商品そのものの形・比率・素材の見え方 |

プロンプトには **「これは MORU のブランドデザイン基準である」と明示**して ① を添える。
**②を渡すので、商品の形は再現される。「実物を切り抜いて背景だけ差し替えろ」といった指示は書かない**(D-069)。

**アクセントカラーは特定色に固定しない**(D-070)。シートに「ブルー×テラコッタ」とあっても**そこは踏襲しない。**
カラフル・ポップな方向で、商品ごとに色味を変えて展開してよい。守るのは
「**差し色は1〜2色まで / 商品が主役 / 余白 / 明るい自然光**」という**使い方**のほう。

**ただし「1〜2色」は色数の話でしかない。面積と彩度も必ず指示する(D-076)。**
数だけ書くと、モデルは**画面のいちばん大きい面(商品の足元のラグ)を1色で塗ってくる。**
実際、コーデュロイ フォールディングチェアの検証で**ラグのほうが目立ち、椅子が主役でなくなった。**

| 指示すること | 内容 |
|---|---|
| **面積** | 差し色は**商品から離れた小物だけ**(花瓶・本の背・壁のアート)。画面の数パーセント |
| **彩度** | **商品より彩度の高いものを背後や足元に置かない** |
| **足元** | 商品の真下・背後のラグは**無地・低彩度**(オフホワイト / オートミール / 淡いグレージュ / 砂色)。柄を入れない |
| **検証** | 目を細めて見て、最初に目に入るのが商品か確かめる。**明らかに背景が勝っているときだけ作り直す。迷う程度なら通して進む**(ここで止まると作業が終わらない) |

英文の定型は `references/higgsfield_recipe.md` の `ACCENT DISCIPLINE` ブロックをそのまま使う。

**色温度も必ずロックする(D-077)。** 指定しないと**ゴールデンアワー・ハニーオーク床・
全体に暖色のフィルター**に落ちて、抜け感が出ない。

- **5200〜5600K / 午前の光 / 白は白のまま。** ゴールデンアワー・夕方・ランプ光は禁止
- 名指しで避ける: **北欧 hygge の暖かさ / 韓国インテリア風の warm ベージュ / 秋色 / オレンジ寄りのハニーオーク床**
- 床は**淡いオークかアッシュ**、壁は**寒色寄りのオフホワイト**(クリームにしない)
- **暖色を全部消さない。** 木とオフホワイトは基調。消すのは全体にかかった暖色フィルター

英文定型は `references/higgsfield_recipe.md` の `LIGHT TEMPERATURE LOCK` / `AIRINESS`。

> ⚠️ **リファレンスシート自体が暖色寄り**なので、これは対症療法。
> シートの差し替え指定は `docs/brand/reference-sheets/README.md` の「シート側の課題」。

#### 生成は Higgsfield / GPT Image 2 / quality low(D-073)

**画像生成はすべて Higgsfield で行う。** モデルは **`gpt_image_2`**、**quality は `low`** で固定。
**実行手順・プロンプト骨格・実測値は `references/higgsfield_recipe.md` を見る。**
コストは **0.5 クレジット/枚**。`count: 2` で別案を2枚出し、良いほうを採る。

#### 枚数の目安(D-071 / D-074)

| タイプ | 枚数 |
|---|---|
| A サムネイル | **バリアントの数だけ**(1色なら1枚。5色なら5枚) |
| B 商品画像 | **5枚程度**(バリアント別には作らない) |
| C 説明画像 | **3枚程度**(バリアント別には作らない) |

**バリアント展開はサムネイルだけ**(D-074)。5色の商品なら **サムネ5 + 商品画像5 + 説明画像3 = 13枚**。
1色の商品なら 1 + 5 + 3 = **9枚**。必要なら増やしてよい。

#### A. サムネイル(一覧・カテゴリ用)— シート03準拠

- 参照: **`03_thumbnail_rules.png` + `01_brand_visual.png` + 商品画像**
- 白抜き禁止。**明るい生活シーンの中に置く**
- 背景は整える(木の棚・白壁・植物程度)/ 商品が主役 / 周囲に余白
- **一覧に並べたとき同じ部屋の写真に見えること**(世界観の統一が最優先)

#### B. 商品画像(メイン・サブ)— シート02準拠

- 参照: **`02_product_image_rules.png` + `01_brand_visual.png` + 商品画像**
- **5点構成**: メイン(生活シーン)/ ディテール / 素材感 / 使用シーン / サイズ感
- **形状比率を変えない。** 寸法・構造を変える生成をしない(CLAUDE.md 絶対ルール9)
- ペットを入れる場合は自然に(シート02 下部のルール)

#### C. 説明画像 — シート05準拠

- 参照: **`05_description_image_rules.png` + `01_brand_visual.png` + 商品画像**
- **3点程度**: ① 素材・質感 / ② ディテール / ③ 使用シーン
- **寸法図は生成しない。** 白背景・正面+側面の2ビュー・細い引き出し線と数字だけなので、
  **HTML/テンプレートで作るほうが確実**(生成でごまかさない)
- 日本語文字が要る場合は ①文字編集に強いモデルで置換 → ②崩れたら HTML で作り直す
- 文字・図はシンプル(ゴシック1書体)/ 余白を活かす / トーン統一 / 読みやすく
