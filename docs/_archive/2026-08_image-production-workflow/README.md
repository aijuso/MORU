## 戻すときに価値が残っているもの

この4ファイルの中で、**規模が出たあとも効く知見**は次の3つ。

1. **参照画像は2種類渡す**(ブランド基準 + 商品画像)。テキストで世界観を説明しても効かない
2. **商品画像は「物体だけ」と明示しないと撮影環境まで引き継ぐ。** 背景・床・幅木・カメラ高・画角を個別に否定する
3. **「差し色は1〜2色」は色数の話でしかない。** 面積・彩度・置き場所を書かないと、
   モデルは画面最大の面(足元のラグ)を1色で塗り、商品が主役でなくなる
