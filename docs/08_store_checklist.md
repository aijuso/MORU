# 08. ストア運用チェックリスト(商品登録マニュアル + 残タスク)

> 2026-08-22 作成。商品コンテンツをメタフィールドで管理する設計に切り替えたときの申し送り。
> **管理画面 = 入力フォーム、テーマ = 表示** という役割分担。商品ごとに変わる文言は
> テーマエディタではなく、管理画面の商品編集画面で入力する。

---

## §1 新しい商品を登録するときの入力項目

管理画面「商品 → 商品を追加」で入力するもの。テーマは以下を読んで表示を組み立てる。

### 標準フィールド

| 項目 | 入力内容 | 表示される場所 |
|---|---|---|
| タイトル | 例: MORU フラワーラウンジ | 商品ページ・カード・検索 |
| 説明 | 2〜3段落の概要のみ(詳細はメタフィールドへ) | 「商品説明」アコーディオン(初期展開) |
| メディア | 商品写真のみ。**仕入元のマーケ画像は登録しない** | ギャラリー(1枚目がメイン) |
| 価格 | 税込。**二重価格(compare at price)は原則使わない**(docs/00 第12章) | 価格表示 |
| 在庫 | 「在庫を追跡する」を必ずオン。数量を入力 | 残りわずか表示・売り切れ判定 |
| オプション名 | **必ず「カラー」**(または「色」「Color」)。それ以外の名前だと丸スウォッチにならない | カラー選択 |
| バリアント画像 | **各カラーに画像を割り当てる**。無いと色を替えても写真が変わらない | ギャラリー連動 |
| 商品タイプ | 例: 猫用ベッド | カードのサブタイトル・コレクション自動振り分け |
| タグ | カテゴリーページのタブになる。**タブに出したい言葉だけ**付ける(例: ベッド) | 絞り込みタブ |
| 販売チャネル | **「オンラインストア」に公開されているか必ず確認**。仕入れアプリ経由の商品は POS のみになっていることがある(今回実際にあった) | 公開可否 |

### メタフィールド(商品編集画面の下部にピン留め済み)

| 欄 | 型 | 書くこと | 表示される場所 |
|---|---|---|---|
| 一言コピー | 複数行テキスト | 2行程度の世界観コピー | 価格下のリード文 |
| サブタイトル | 1行テキスト | 素材/カラーの補足。バリアントがある商品では選択中のバリアント名が優先されるので空でよい | 商品名の下 |
| 素材・サイズ | リッチテキスト | 確認済みの仕様のみ箇条書き。**無垢材・完全防水・丸洗い可能は書かない**(docs/00 第5章) | 「素材・サイズ」アコーディオン |
| 特徴 | メタオブジェクト(商品の特徴)のリスト | 1件 = 画像+見出し+本文。3〜5件。先に「コンテンツ → メタオブジェクト → 商品の特徴」でエントリを作り、ここで選ぶ | 「この商品の特徴」の交互レイアウト |

未入力でも壊れない(リード文はセクション設定へ、特徴はテーマエディタのブロックへフォールバック)。

### 文言のNG(docs/00 第11章)

絶対に使ってくれる / どんな猫にも最適 / 100%安全 / 完全防水 / 一生使える / 業界No.1 /
残りわずか(事実でない場合) / 本日限定(毎日更新する場合) / 「即納」「国内発送」と誤認させる表現

## §2 ユーザーの操作が必要な残タスク(APIからは設定不可)

| # | 場所 | やること |
|---|---|---|
| 1 | 設定 → 商品のオプション | オプション「カラー」の値にスウォッチ色を設定(アイボリー: #F5F0E6 系 / オリーブグリーン: #6B7049 系)。設定すると商品カード・商品ページの丸スウォッチに色が付く |
| 2 | 割引 | 発売記念10%OFF を「自動割引」で作成(商品価格 9,980円 → 8,982円)。二重価格表示ではなく割引機能で行うのが docs/00 の方針 |
| 3 | 割引 | アナウンスバー訴求用のクーポンコード(新規会員 ¥500 相当など)。カートのクーポン欄は `/discount/コード` を使うので作成すれば実際に効く |
| 4 | アプリ | **Search & Discovery**(無料・Shopify製)を追加 → 検索の同義語・並び順・おすすめ商品を調整できる |
| 5 | 設定 → 決済 | スピードアップチェックアウトを有効化(Shop Pay / Apple Pay / Google Pay) |
| 6 | テーマエディタ | 特商法ページの事業者情報(販売業者・所在地・電話番号など)を入力 |
| 7 | ページ | about / tokushoho / privacy / terms / faq の5ページを内容確認後に公開 |
| 8 | オンラインストア → メニュー | メインメニューが Home / Catalog / Contact のまま。「新着アイテム(/collections/new-arrivals)」「猫のくらし(/collections/cat-life)」「MORUについて」「よくある質問」等に差し替え |
| 9 | 商品写真 | ギャラリー2枚目(Soft & Breathable の英語インフォグラフィック)と特徴セクションの画像は仕入元由来。ブランド写真が用意でき次第差し替え |
| 10 | 公開直前 | **ストアパスワードを変更してから解除**(現在のパスワードはチャットで共有されたため) |

## §3 今回ストア側に作ったもの(2026-08-22)

- メタフィールド定義(商品・すべてピン留め): `custom.catch_copy` / `custom.subtitle` / `custom.specs` / `custom.features`
- メタオブジェクト定義: `moru_feature`(画像/見出し/本文)。フラワーラウンジ用に4エントリ作成済み
- 商品「MORU フラワーラウンジ」(handle: `moru-flower-lounge`、ACTIVE、オンラインストア公開済み)
  - カラー: アイボリー / オリーブグリーン(各 ¥9,980・在庫3・バリアント画像割当済み)
  - 仕入元の中国語マーケ画像19枚をギャラリーから除外(ファイル自体は「コンテンツ → ファイル」に残っている)
- コレクション: 「新着アイテム」`new-arrivals`(自動: 価格>0)/「猫のくらし」`cat-life`(自動: 商品タイプ=猫用ベッド または タグ=猫のくらし)
- 英語サンプル商品4点は削除(ユーザー指示)
