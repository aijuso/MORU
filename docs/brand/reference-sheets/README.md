## ⚠️ 画像生成での使い方(D-068)

**これらの PNG は「読んで参考にする」ものではなく、画像生成の参照画像として実際に渡すもの。**

- 生成プロンプトには **「これは MORU のブランドデザイン基準である」と明示**して、該当シートを添付する
- **同時に、その商品の Shopify 登録済み商品画像も参照として渡す**(形状の正)
- 詳細な手順は `docs/11_product_registration_workflow.md` §6
