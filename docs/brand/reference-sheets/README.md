## ⚠️ シート側の課題(2026-08-24・オーナー指摘 / D-077)

**シート01・03 を参照画像として渡すと、出力が暖色に寄る。**
北欧系のこもった暖かさ・韓国インテリア風の warm トーン・夕方の光に落ちてしまい、
MORU が求める**抜け感(明るく・軽く・空気が通る)**にならない。

### 原因(シートを読み直して特定したもの)

| # | 何が暖色を引っぱっているか | どこ |
|---|---|---|
| 1 | **メイン写真の光がやや夕方寄り。** 床への当たりが golden hour に見える | シート01 上部の大判写真 |
| 2 | **床材がハニーオーク**(オレンジ寄りの中間色)。9枚中ほぼ全部がこの床 | シート01・03 の全カット |
| 3 | **マスタードのプフ・テラコッタの花瓶**が大きく写り、暖色の面積が広い | シート01 |
| 4 | **9色パレット自体が暖色多数**(ウォールナット / テラコッタ / マスタード)。
寒色は MORUブルーとクロームグレーのみで、しかも生成では青アクセントを外した(D-070) | docs/01 §2 |
| 5 | 壁がクリーム寄りのオフホワイトで、白が白として立っていない | シート01・03 |

**4番が構造的な問題。** ブランドの抽象的な方向(暖色中心のパレット)と、
写真に求める質(明るい・抜け感・白が白)が噛み合っていない。
**プロンプト側のロックは対症療法**であって、根治はシートの差し替え。

### 差し替えるときの指定(次にシートを作るときの申し送り)

- **光**: 午前の光。5200〜5600K。**ゴールデンアワー・夕方・ランプ光を使わない**
- **床**: **淡いオーク / アッシュ / 白木**。オレンジ寄りのハニーオークをやめる
- **壁**: **寒色寄りのオフホワイト**。クリームにしない
- **暖色の面積を減らす**: マスタードやテラコッタの大物家具を主役級に置かない。
  暖色は小物の範囲に留める
- **余白を増やす**: 現状は物が多め。抜け感は「置かないこと」でつくる
- **暖色を全部消さない**: 木とオフホワイトは MORU の基調なので残す。
  消すのは**全体にかかった暖色のフィルター**

### それまでの運用

プロンプトに **`LIGHT TEMPERATURE LOCK`** と **`AIRINESS`** ブロックを必ず入れる。
定型文は `.claude/skills/product-registration/references/higgsfield_recipe.md`。
