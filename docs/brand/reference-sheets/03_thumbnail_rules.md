## 結論

**白抜き(白背景の商品単体)ではなく、「明るい生活シーンの中の商品」がサムネイルの正。**

docs/01 v0.1 の「商品一覧の1枚目は Warm Ivory系背景・文字なしで統一」は
**この方針に置き換わる**(背景を単色にするのではなく、整えた生活シーンにする)。

## ルール(シート下部の6項目)

| ルール | 実装上の意味 |
|---|---|
| **明るい生活シーン** | 白抜き禁止。窓光のある部屋に置く |
| **背景は整える** | 木の棚・白壁・植物程度に絞る |
| **差し色は1〜2色** | ブルー / テラコッタ。両方入れるなら他は入れない |
| **商品が主役** | サムネで何の商品か1秒で分かること |
| **余白** | 商品の周囲に余白。フレームぎりぎりに置かない |
| **世界観を統一** | 一覧に並べたとき同じ部屋の写真に見えること |

## 一覧全体で守るトーン(シート最下部の帯)

- ペットと心地よく暮らせる
- ミッドセンチュリー / 新レトロ
- ナチュラル素材とやさしい質感
- ブルー × テラコッタのアクセント
- 明るく、清潔感のあるトーン

## 制作方針(docs/05・商品登録スキル v2 と連動)

**フル生成より「実物写真の切り抜き + 背景差し替え」を優先する。商品ピクセルは極力触らない。**
