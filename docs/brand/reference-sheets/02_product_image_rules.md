# シート02 — 商品画像ルール(メイン画像)

> 受領 2026-08-23 / ページ表記 `02/05` / 画像版は未収録(README 参照)
> **商品ページのメイン画像・サブ画像の構成の正。**

## 例に使われている商品

グレーのブークレ張り「ペット用オフィスチェア」(昇降ガス圧+5本脚キャスター)に黒猫。
背景はブルーの収納キャビネット、観葉植物、ブルー×オフホワイトのラウンドラグ、窓の自然光。

## 5点構成(この順で揃える)

| # | 役割 | 中身 |
|---|---|---|
| 1 | **メイン(生活シーン)** | 商品が部屋に置かれ、ペットが自然に使っている引き画。最大サイズで見せる |
| 2 | **ディテール** | アーム/縫製/可動部などの寄り |
| 3 | **素材感** | 生地・木目のマクロ。手触りが想像できる密度 |
| 4 | **使用シーン** | 別アングル。ペットの向き・行動が1枚目と違うもの |
| 5 | **サイズ感** | 商品単体+寸法注記(例: 約70cm)。**寸法線はシンプルな細線+数字のみ** |

## ルール(シート下部の6項目)

| ルール | 実装上の意味 |
|---|---|
| **自然光** | 窓光。硬い影・色かぶりを作らない |
| **商品が主役** | 商品をフレーム中央〜黄金比位置に。背景物で食わない |
| **背景は整える** | 生活感は出すが散らかさない。不要物は除く |
| **差し色を活かす** | ブルー×テラコッタ。1画面1〜2色 |
| **ペットは自然に** | ポーズを作らない。使っている/くつろいでいる状態 |
| **余白を残す** | 上下左右にゆとり。トリミングで詰めない |

## 禁止・注意(docs/01 と共通)

- 実物と形状・サイズが変わる生成をしない(**形状の正は常に実物写真**)
- 中国EC由来の文字入り画像をそのまま使わない
- 実際より大きく見せる合成をしない
