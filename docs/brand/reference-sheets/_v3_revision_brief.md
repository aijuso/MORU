# MORU LIVING ブランドリファレンスシート 改訂依頼

添付した5枚が現行のリファレンスシート(v0.2)です。これを**改訂版(v3)に作り直したい**。
5枚はそのままリファレンスとして使い、構成は活かしつつ、下記の問題を直してください。

## 0. このブランドについて(最低限の前提)

- ブランド名: **MORU**(正式名称 MORU LIVING)。日本のD2C
- 定義: **Pet-first, Interior-always.** ペットと人が一緒に心地よく暮らせる**インテリアブランド**
- **ペット用品専門店に見せない。** 猫家具は入口であって、主戦場はインテリア
- **禁止**: 猫耳・肉球・猫シルエットのモチーフ。高彩度のペットショップ風。ロゴの改変
- 9色パレット(これは変更しない):
  オフホワイト `#F7F7F5` / ライトベージュ `#E9E3D9` / ウォールナット `#7B5A3C` /
  テラコッタ `#D65832` / マスタード `#F2C23A` / MORUブルー `#1E5B8F` /
  モスグリーン `#6A7D5B` / クロームグレー `#B6BBC1` / チャコール `#2E2E2E`

## 1. 5枚それぞれの役割

| # | シート | 役割 |
|---|---|---|
| 01 | ブランドビジュアル | 配色・光・トーンの全体像。**他4枚の温度を決める親** |
| 02 | 商品画像ルール(メイン画像) | 商品ページに載せる5点構成の見本 |
| 03 | サムネイル画像ルール | 一覧・カテゴリページの1枚目の見本(10点) |

**これらは人が読む資料であると同時に、画像生成AIに参照画像としてそのまま渡すものです。**
つまりシートに写っている光・床・色の面積が、そのまま生成される商品写真に転写されます。
そこが今回の問題の根っこです。

## 2. 何が問題か(実際に起きたこと)

現行シートを参照画像として商品サムネイルを生成したところ、**3つの失敗が再現しました。**

### 問題A: 出力が暖色に寄る。抜け感が出ない

生成結果が毎回**金色がかった夕方の光・ハチミツ色のオーク・全体に暖色のフィルター**になり、
**北欧hyggeのこもった暖かさ / 韓国インテリア風のwarmベージュ / ゴールデンアワー**のどれかに落ちました。
MORU が欲しいのは**明るく・軽く・空気が通る「抜け感」**で、真逆です。

**シート側の原因(こちらで特定済み):**

1. シート01 の主写真の光が**夕方寄り**。床への当たりがゴールデンアワーに見える
2. **床がハニーオーク**(オレンジ寄りの中間色)。ほぼ全カットが同じ床
3. **マスタードのプフ・テラコッタの花瓶**が大きく写り、暖色の面積が広い
4. **壁がクリーム寄りのオフホワイト**で、白が白として立っていない
5. **9色パレット自体が暖色多数。** 寒色は MORUブルーとクロームグレーのみ

### 問題B: 差し色が主役の商品を食う

シート03 の10枚は、**ほぼ全部が色付きのラグを画面最大の面積に置いています。**
これを参照した生成AIは「**足元を1色で塗ってよい**」と学習し、
実際に**マスタードやモスグリーンの大きな円形ラグのほうが目立ち、主役の椅子が沈みました。**

**「差し色は1〜2色」は色数の話でしかなく、面積と彩度の指定が抜けています。**

### 問題C: アクセントが「ブルー×テラコッタ」に固定されている

シートは差し色をブルーとテラコッタで統一していますが、**この固定はやめます。**
商品ごとにカラフル・ポップに色味を変えたい。**守りたいのは色そのものではなく、
「絞る・小さく置く」という使い方のほうです。**

## 3. 全シート共通の新基準(5枚すべてに適用)

### 光と色温度

- **午前の光。5200〜5600K。正確なホワイトバランス。白は白のまま**
- **禁止: ゴールデンアワー / 夕方 / ランプ光 / アンバーの被り / セピア / 秋色**
- 明るく均一なフィル、**影は浅く**、コントラストは穏やか

### 素材と面

- **床: 淡いオーク / アッシュ / 白木。** オレンジ寄りのハニーオークをやめる
- **壁: 寒色寄りのオフホワイト。** クリームにしない
- **暖色を全部消すのではない。** 木とオフホワイトは MORU の基調なので残す。
  **消すのは全体にかかった暖色のフィルターと夕方の光だけ**

### 差し色(最重要)

- **商品の真下・背後のラグは、無地・低彩度**(オフホワイト / オートミール / 淡いグレージュ / 砂色)。
  **柄を入れない。** 商品を床から分離するためだけの存在
- **差し色は、商品から離れた小物にだけ**(花瓶・本の背・壁のアート)。**画面の数パーセント**
- **商品より彩度の高いものを、背後にも足元にも置かない**
- 検証: **目を細めて見て、最初に目に入るのが商品であること**

### 抜け感

- **物を減らす。** 抜け感は「置かないこと」でつくる
- 余白を広く。商品の周囲に呼吸する空間を残す
- cosy / dim / moody にしない

## 4. シート別の修正指示

### シート01 ブランドビジュアル ★最優先

**このシートが他4枚の温度を決めるので、最初に確定させてください。**

| 対象 | 指示 |
|---|---|
| 主写真(大判) | 構図とモチーフ(猫+ラウンジチェア+サイドボード+棚)は維持。**光を午前に。床を淡いオークへ。壁を寒色寄りのオフホワイトへ** |
| **マスタードのプフ** | **暖色の一番大きい塊。外すか、小さいスツール／小物に降格させる** |
| テラコッタの花瓶 | 残してよいが**小さく**。画面を支配させない |
| 物量 | **減らす。** 棚の小物を間引き、余白を増やす |
| 右の4原則アイコン | **「青アクセント」を「差し色は小さく」に差し替え**(理由は問題C) |
| **カラーパレット9色** | **変更しない。** 色見本・色名・HEX はそのまま |
| 背景イメージ3枚 | 同じ新基準で作り直し |
| ライティング3枚 | 同じ新基準で作り直し。**「夕方の窓」に見えるカットを使わない** |

### シート03 サムネイル画像ルール ★問題Bの元凶。10枚とも作り直し

| 対象 | 指示 |
|---|---|
| 10枚の構図 | **1枚1商品・生活シーンの中・白抜き禁止・余白たっぷり**は維持 |
| **足元** | **10枚すべて、ラグを無地・ほぼ無彩色に。** 大きな色面をつくらない |
| **差し色** | **小物へ移す。** そのうえで**10枚で色をバラす**(モスグリーン/イエロー/コーラル/ライラック/ブルー等)。
「カラフル・ポップ」は**面積ではなく種類の多さ**で表現する |
| 商品の並び | ペットが写るのは10点中3〜4点まで(ペット専門店に見せないため。現行の比率は適切) |
| 下部のルールチップ | 「差し色は1〜2色」→ **「差し色は小さく」**に変更。さらに
**「商品より目立つ色面を置かない」**のチップを1つ追加 |

### シート02 商品画像ルール(メイン画像)

**5パネル構成(メイン/ディテール/素材感/使用シーン/サイズ感)は良いので維持。**

| 対象 | 指示 |
|---|---|
| **青いキャビネット** | **淡い木の家具に置換。** 青の大きな面をなくす |
| **青いラグ** | **ほぼ無彩色に。** 差し色は小物1〜2点へ |
| 猫 | **残す。**「ペットは自然に」はブランドとして正しい |
| サイズ感パネル | 「約70cm」の引き出し線の出し方は良いので**維持** |
| 光 | 新基準へ |

### シート05 説明画像ルール

| 対象 | 指示 |
|---|---|
| ① 素材・質感 / ② ディテール / ④ 使用シーン | **写真3点を新基準で作り直し** |
| **③ サイズ・寸法** | **作り直さない。現行のまま維持。**
白背景・正面+側面の2ビュー・細い引き出し線と数字だけ、というこの見本が正しい。
**この寸法図は生成ではなく作図で作る運用**なので、見本としてそのまま残す |
| ④ 使用シーン | **マスタードのプフをここでも外す**(シート01と同じ理由) |

### シート04 カテゴリー別アングル早見表 ▼後回し

**今回は触らない。** このシートの仕事は色ではなく**アングル**で、18分類の指定は現状で機能しています。
01〜03・05 が固まってから、温度合わせのためだけに最後に回してください。

## 5. 出力について

- **サイズ・レイアウト・書式は現行シートを踏襲**(横長・上部にMORUロゴと見出し・右上にページ番号 `0X/05`)
- **日本語のキャプションは現行の文言をそのまま使う。**(上で差し替えを指定した箇所だけ変更)
- ⚠️ **日本語の文字が崩れる場合は、無理に文字を描き込まないでください。**
  その場合は**中の写真だけを個別に出力**してもらえれば、こちらで体裁を組み直します。
  **崩れた日本語が入ったシートより、写真だけのほうが役に立ちます**
- 1枚ずつ出してください。**まずシート01だけ**を出して、温度の方向性を確認させてください

## 6. 受け入れ基準(この5点で判定します)

1. **白が白に見える。** 全体に暖色のフィルターがかかっていない。夕方の光になっていない
2. **床がオレンジ寄りのハニーオークでない**
3. **画面最大の面積が、彩度の高い色で塗られていない。** 特に商品の足元
4. **目を細めて見て、最初に目に入るのが商品**
5. **物が減って余白が増えている**(抜け感)
