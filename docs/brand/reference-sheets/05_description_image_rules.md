# シート05 — 説明画像ルール

> 受領 2026-08-23 / ページ表記 `05/05` / 画像版は未収録(README 参照)
> **商品ページ本文(descriptionHtml / メタフィールド)に載せる説明画像の正。**

## 4点セット(この4つで1組。過不足なく作る)

### ① 素材・質感
- ブークレ生地などのマクロ写真。繊維1本まで見える寄り
- **カラーバリエーションを丸スウォッチで併記**(シートでは4色の円が下部に並ぶ)
- アイコン: 質感を示す小さな丸バッジ(左上)

### ② ディテール
- 主役1枚(例: 木脚と本体の接合部)+ **右に縦3分割のサブ寄り**
- 見せるのは「作りの良さが分かる箇所」: 縫製・木口・脚裏のフェルト等
- アイコン: 虫めがね(左上)

### ③ サイズ・寸法
- **白背景で商品単体を正面+側面の2ビュー**
- 寸法は細い引き出し線 + 数字のみ(シート例: 高さ38cm / 幅72cm / 奥行36cm)
- 装飾線・影を付けない

### ④ 使用シーン
- 実際の部屋に置いた引き画。ペットが自然に使っている
- ブランドビジュアル(シート01)と同じ光・同じ配色
- アイコン: 家(左上)

## ルール(シート下部の4項目)

| ルール | 実装上の意味 |
|---|---|
| **文字・図はシンプル** | 装飾書体・袋文字・影付き文字を使わない。ゴシック1書体 |
| **余白を活かす** | 図版の周囲に十分な余白。四辺いっぱいに詰めない |
| **トーンを統一** | 4枚の色温度・明度を揃える。1枚だけ暗い/黄色いを作らない |
| **読みやすく** | 文字は最小でも本文相当。細い明朝の極小文字にしない |

## 制作方針(商品登録スキル v2 と連動)

仕入れ元の説明画像に中国語等の文字が乗っている場合:

1. **文字編集に強いモデルで日本語に置換**する
2. **崩れたら HTML/テンプレートで図版を作り直す**(生成でごまかさない)

**寸法・素材の数値は仕入れ元資料の実値のみ。推定値を図に書かない。**
