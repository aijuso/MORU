# シート01 — ブランドビジュアル リファレンスシート

> 受領 2026-08-23 / ページ表記 `01/05` / 画像版は未収録(README 参照)
> **配色・光・トーンの最上位リファレンス。**

## キービジュアル(シート上部の大判写真)

明るいリビング。窓から自然光が斜めに差し込む。

- 主役: **オフホワイトの花びら型ラウンドチェア(フラワーラウンジ系)に丸くなるキジトラ猫**
- 木部: 明るいオーク/バーチのローボード・丸テーブル(ダークウォールナットに寄せない)
- 青アクセント: **ブルーのマッシュルーム型テーブルランプ**、ブルーのマグ、ブルーの金属シェルフ
- テラコッタアクセント: 壁のアート(オレンジ・ブルー・グリーンの円形)、シェルフ上のテラコッタの壺
- 差し色: マスタードのラウンドプフ
- 足元: ブルー×テラコッタ×オフホワイトの抽象形ラグ
- ペット要素: 右奥にベージュのキャットタワー(**主張させず、部屋に溶け込ませる**)
- グリーン: 観葉植物を複数、鉢はオフホワイト/ベージュ

**読み取れる原則: ペット用品を「隠さないが、目立たせない」。部屋の完成度が主語。**

## 4原則(シート右カラム)

| 原則 | 意味 |
|---|---|
| **明るい自然光** | 窓光ベース。ストロボの硬い影を作らない |
| **抜け感** | 詰め込まない。視線が奥へ抜ける構図 |
| **清潔感** | 白〜ベージュの面積を広く。彩度を上げすぎない |
| **青アクセント** | MORUブルーを画面のどこかに必ず1点置く |

## 背景イメージ(シート中段右・3点)

いずれも「生活が成立している明るい部屋」。白い壁 + 明るい木 + 植物 + ブルー/テラコッタ小物。

1. オフホワイトのソファのあるリビング(ブルー系ラグ、丸テーブル)
2. ダイニング(木の丸テーブル+ペンダントライト+ブルーのチェア)
3. コンソール/シェルフの壁面(ブルーのアート、テラコッタの器)

## ライティング(シート下段)

- **明るい自然光**: 薄いカーテン越しの窓光。影はやわらかく長い
- **抜け感**: 壁に落ちる枝葉の影を積極的に使う。空気が動いている感じ
- 光源図: **窓は被写体の斜め前〜横**から。真正面からのフラットライトにしない
