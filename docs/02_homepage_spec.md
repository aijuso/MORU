## 全体ルール

- 右サイドバー禁止。**Full-width セクションの縦積み**
- 背景は **オフホワイト `#F7F7F5`** と **ライトベージュ `#E9E3D9`** を交互に。罫線に頼らない
- アクセントは **MORUブルー × テラコッタ**のペア。差し色は1画面1〜2色(docs/01 §2)
- モバイルは同順の縦積み。カルーセルは見切れ表示(1.2〜1.5枚)で「横に続く」ことを示す
- すべてのセクションは**テーマエディタから編集可能**(schema 必須・日本語ラベル・presets 必須)
- 文言は `locales/ja.default.json` の翻訳キー経由。**Liquid 直書き禁止**

## 1. Announcement Bar

- **黒地・白文字**の細いバー(この配色は v1 から一貫して不変。docs/07 §3)
- 文言例: `新規会員登録で500ptプレゼント`
- ⚠️ **ポイント制度(500pt)の実施は未決。実施が決まるまでこの文言はプレースホルダー扱い。**
  実施しないまま出すと虚偽表示になる。テーマ設定から差し替え可能に保つ
- 偽の残数・カウントダウン禁止

## 2. Header

**仕様は `docs/09_navigation_taxonomy.md` §2・§3 が正。** 要点のみ:

- 中央 MORU ロゴ / トップレベル5項目 / 「インテリア ▾」ドロップダウン6項目
- モバイル: ☰ + 中央ロゴ + 検索・カート(**カート常時表示**)、
  インテリアはアコーディオン、下段に信頼情報3項目、最下部にSNS

## 3. Hero(カルーセル対応)

- Full-width。**複数スライドをブロックで登録可能**(1枚運用も可)
- コピー例:
  - 見出し `猫が心地よく眠れる、わたしも好きな部屋へ。`
  - サブ `やわらかい時間が流れる、私の部屋。`
  - ボタン `フラワーラウンジを見る` → 商品ページ直リンク
- 写真はシート01の4原則(明るい自然光 / 抜け感 / 清潔感 / 青アクセント)
- 文言・画像・リンクはすべて設定から編集可能

> **未回答だった論点への回答**: docs/06 §0 に「ヒーロー見出しを差し替えるか未回答」と
> 残っていた件は、v0.2 プロンプトが `猫が心地よく眠れる、わたしも好きな部屋へ。` を
> ヒーローのコピー例として提示したことで**事実上こちらに寄った**と読める。
> ただしプロンプトの表記は「コピー例」であり「確定」ではない。
> **実装着手時にオーナーへ最終確認する。** 現行実装は v2 の `猫が寝転ぶと、部屋が完成する。` のまま。

## 4. 信頼バッジ帯(4項目)

| # | 項目 | 暫定文言 |
|---|---|---|
| 1 | 送料無料条件 | **ストアの実設定と一致させる**(現状 ¥7,700 / 下記⚠️) |
| 2 | お届け目安 | **正直表記**(例: `ご注文から2〜3週間でお届け`) |
| 3 | 返品・交換 | `30日間返品・交換` ※ポリシー確定後に確認 |
| 4 | 品質基準 | `ペットのための品質基準` |

### ⚠️ 使ってはいけない文言

- **「最短翌日お届け」は使用不可。** 海外取り寄せモデルで事実に反する。
  モックにこの文言があっても**そのまま使わない**
- 送料無料しきい値は**ストア設定と一致させる。**
  現在トップは「税込15,000円以上で送料無料」と表示しているが、**ストア設定は ¥7,700 のまま。**
  この乖離は虚偽表示。**表示を直すかストアを直すかの判断が必要**(docs/06 §0 の未解決項目)

**最終文言はサンプル実測と CKB 配送条件の確定待ち — PENDING。**

## 5. ベストセラー(5商品)

- 5商品を横並び。**1〜5位の番号バッジ**(v0.2 で解禁)
- ⚠️ **販売実績が出るまで順位を出さない。**
  暫定は「人気アイテム」等、**実績を偽らない見出し**にする(docs/01 §4)。
  実績が出たら番号バッジをONにする(schema にトグルを持たせる)
- **現状 5枠は商品未選択**(商品が1点しかないため)。テーマエディタから選ぶ

## 6. 新着アイテム(カルーセル)

- 見出し `新着アイテム` / 右 `すべて見る →`
- 横カルーセル。デスクトップ4枚表示、左右矢印 + progress bar
- **NEWバッジ使用可**(v0.2 で解禁)。付与条件は「公開から N 日以内」等、事実に基づく規則で
- カード: 正方形画像 / 商品名(日本語)/ 価格
- **サムネは白抜き禁止。明るい生活シーンの中の商品**(シート03)
- 商品カードの角はほぼ直角(docs/07 §3 の不変仕様)

## 7. 部屋で見る(Shop the Room)

**v3 で最も変更が大きいセクション。**

- **スタイル別タブ**: `ミッドセンチュリー` / `カラフルポップ韓国風` / `北欧` / `ジャパンディ`
- 各タブ = 1ルーム。ブロックで登録
- 左2/3: 部屋写真 + **ホットスポット**(円ドット、最大6)
- 右1/3: 小見出し / 説明1行 / 商品リスト縦4件(小サムネ+名前+価格)
- **`このセットをまとめて購入` ボタン**(タブ内の全商品をカートに入れる)
- ペット商品と人用商品を**同じ部屋に混ぜる**(Value ③ Shared Space の体現)

> ⚠️ 「まとめて購入」は複数バリアントの一括 add。在庫切れが1点でもある場合の
> 挙動(全部止める / 在庫のあるものだけ入れる)を決める必要がある — **PENDING**

## 8. プロモバナー2枚

- 2枚横並び(モバイル1列)。**テーマ設定で個別に ON/OFF**
- 内容例: `組み合わせ割` / `シーズンセール`
- 画像1枚 + 内部リンクの構成(既存 `moru-cta-banners` の仕様を踏襲)。
  推奨解像度 1440×480 / 3:1
- ⚠️ **実施していない割引のバナーを出さない。** 割引は Shopify 側で実際に設定してから出す

## 9. カテゴリーから探す

- **円形カテゴリサムネを横一列に6個。** ラベルは `docs/09` §1 の6分類:
  `ペット / チェア・スツール / テーブル / 照明 / ファブリック / 雑貨`
- アクティブ: ウォールナットの細いリング。非アクティブ: ライトベージュのボーダー
- 下に**正方形商品カード 4列 × 2行 = 8個**。カテゴリ切替でフェード入れ替え
- 下部中央にアウトラインボタン(カテゴリに追従。例 `すべてのチェア・スツールを見る`)
- カテゴリ = ブロック { ラベル / サムネ画像 / コレクション }

## 10. #MORUのある暮らし + 読みもの(2カラム)

| カラム | 内容 |
|---|---|
| 左 | **#MORUのある暮らし** — UGC 正方形4枚 + Instagram フォロー導線 |
| 右 | **読みもの** — 記事カード3枚 |

- UGC は手動ブロック型(画像+リンク)。API連携は後回し
- ⚠️ **UGC は実際の投稿のみ。** 自作画像を顧客投稿として出さない
- ⚠️ 読みものは**記事が入るまでプレースホルダー**。ブログ記事は未着手(docs/06)

## 11. 今週のおすすめ

- 小さめ画像の横ストリップ。商品への直リンク
- 「今週」を名乗る以上、**更新されない状態で放置しない**。運用が回らないなら見出しを変える

## 12. Footer

- チャコール `#2E2E2E` 背景 / オフホワイト文字。ロゴは単色版
- カラム: SHOP / CUSTOMER CARE / ABOUT / NEWSLETTER
- 下段: SNSアイコン / 特商法 / プライバシーポリシー / 利用規約
- レイアウトの正は `docs/mockups/footer_20260821.html`(**色は参考にしない** — docs/07 §3)
