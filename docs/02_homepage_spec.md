# 02. トップページ仕様 v2(確定)— MORU LIVING

> 見た目の正: `docs/mockups/home_v2_final.png`
> 方針: LP型ではなく**シンプルなショップ型**。商品を見て→押すと商品ページ、の素直な導線。
> SKUが増えたらセクションを足して育てる前提の設計。

## 全体ルール

- 右サイドバー禁止。Full-widthセクションの縦積み
- 背景は Warm Ivory `#F4EEE5` と Soft Cream `#E8DDCD` を交互に使い、罫線に頼らない
- モバイルは同順の縦積み。カルーセルは「横に続いている」ことが分かる見切れ表示(1.2〜1.5枚)

## セクション構成(確定・この順)

```
1. Announcement Bar
2. Header
3. Hero
4. 新着アイテム(カルーセル)
5. 部屋で見る(Shop the Room)
6. カテゴリーから探す(円形カテゴリ+商品グリッド4×2)
7. 読みもの / 暮らしのヒント
8. Instagram(@MORU_LIVING)
9. Footer
```

※モックで「新着アイテム」が2行連続しているのは生成ノイズ。実装は1つ。
※「カラーで選ぶ」(アイボリーの部屋/オリーブの部屋)はトップには置かず、商品ページ側の要素(docs/03)。

---

## 1. Announcement Bar
- Charcoal背景 / Cream文字 / 細いバー
- 初期文言: `発売記念クーポン配布中`(テーマ設定で変更可)。偽の残数・カウントダウン禁止

## 2. Header
- 中央: ロゴ画像(`docs/brand/logo_terracotta.png` を設定から登録。alt=MORU)
- 左ナビ: 新着 / ペット / インテリア / 雑貨 / 読みもの(Navigation設定から)
- 右: 検索 / ログイン / カートアイコン
- モバイル: ハンバーガー+中央ロゴ+カート

## 3. Hero
- Full-width写真1枚: 明るいリビング(クリームソファ/明るい木の丸テーブル/マッシュルームランプ)+窓辺にフラワーラウンジ(アイボリー)と丸くなる猫
- コピー: `猫が寝転ぶと、部屋が完成する。` + サブ1行(例: `やわらかい時間が流れる、私の部屋。`)
- ボタン: `フラワーラウンジを見る` → 商品ページへ直リンク
- 文言・画像・リンクはすべて設定から編集可能に

## 4. 新着アイテム(カルーセル)
- 見出し: `新着アイテム` / 右: `すべて見る →`
- 6商品登録・デスクトップ4枚表示の横カルーセル。左右矢印+常時見えるprogress bar。autoplayは弱く、操作優先
- カード: 正方形画像(Warm Ivory系統一背景・aspect-ratio 1/1)/ 商品名(日本語)/ 価格。バッジなし
- 初期の並び: フラワーラウンジ(アイボリー)/ フラワーラウンジ(オリーブ)/ マッシュルームテーブルランプ / ラウンドサイドテーブル …
- コレクション指定は設定から

## 5. 部屋で見る(Shop the Room)
- Soft Cream背景のワイドカード
- 左2/3: 部屋写真+ホットスポット(白い + の円ドット、最大6)
- 右1/3: 小見出し(例: `MORU LIVING ROOM`)/ 説明1行 / 商品リスト縦4件(小サムネ+名前+価格)/ Charcoalボタン `この部屋のアイテムをすべて見る`
- ルームはブロックで複数登録可(タブ切替は初期は1ルームでも可、schema上は複数対応)
- ペット商品と人用商品を同じ部屋に混ぜて見せる(USP「カテゴリーを分断しない」の体現)

## 6. カテゴリーから探す
- 見出し: `カテゴリーから探す` / 右: `すべて見る →`
- 円形カテゴリサムネ横一列(5〜6個)。初期ラベル案: `ペット / チェア / テーブル / 照明 / 雑貨`(コレクション設計時に確定)
- アクティブ: Natural Woodの細いリング。非アクティブ: Creamボーダー
- 下に正方形商品カード4列×2行=8個。カテゴリ切替でフェード入れ替え
- 下部中央にアウトラインボタン(例: `すべてのチェアを見る`、カテゴリに追従)
- カテゴリ=ブロック { ラベル / サムネ画像 / コレクション }。初期アクティブは設定から

## 7. 読みもの / 暮らしのヒント
- 記事カード2枚(写真上 / 小タグ / セリフ体タイトル / READ MORE)
- 初期テーマ例: 猫が心地よく暮らせる部屋づくり / やさしい灯りがつくる、くつろぎの時間
- ブログ指定は設定から

## 8. Instagram
- ラベル: `@MORU_LIVING` + 正方形写真5〜6枚の横ストリップ
- 手動ブロック型(画像+リンク)。API連携は後回し

## 9. Footer
- Charcoal背景 / Cream文字。ロゴ(白抜き or Cream単色版)
- カラム: SHOP / CUSTOMER CARE / ABOUT / NEWSLETTER(メール入力)
- 下段: Instagram・Pinterest・LINEアイコン / 特商法 / プライバシーポリシー / 利用規約
