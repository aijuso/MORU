## §1. ナビカテゴリ(7分類・確定)

```
ペット / チェア・スツール / テーブル / 収納 / 照明 / ファブリック / 雑貨
```

**設計意図**: 「ペット」を1分類に閉じ込め、残り6分類を通常のインテリア分類にする。
これで **Pet-first, Interior-always.**(ペット専門店に見えない)がナビの形として成立する。

**「ペット」を先頭に置くのは Hero 商品への導線のため。** 分類数の主従は 1:6。

> **2026-08-23 改訂(D-040)**: 当初は6分類だったが、**「収納」を追加して7分類にした。**
> サイドボード・ナイトテーブル・キャビネットが6分類のどこにも入らず宙に浮いたため。
> 内部タグ `storage` を新設。**トップレベルのヘッダー5項目は変えない**(収納はドロップダウン内)。

## §4. Shopify コレクション設計

ナビ7分類それぞれに対応するコレクションを作る。**すべてスマートコレクション(タグ条件で自動化)。**

| コレクション | handle | タグ条件(いずれかに一致) |
|---|---|---|
| ペット | `pet` | `pet-bed` / `pet-furniture` / `cat-tower` / `pet-goods` |
| チェア・スツール | `chair-stool` | `chair` / `stool` |
| テーブル | `table` | `table` |
| **収納** | **`storage`** | **`storage`** |
| 照明 | `lighting` | `lighting` |
| ファブリック | `fabric` | `rug` / `cushion` / `bedding` / `textile` / `pajama` |
| 雑貨 | `goods` | `mirror` / `object` / `decor` |
| すべてのインテリア | `interior` | 上記のうち **ペット以外の全タグ** |

### 2層設計にしておく理由

将来「ペット」配下を分割する(`pet-bed` / `cat-tower` 等を独立コレクションにする)ときは、
**タグの束ね直しだけで済む。** 商品の再登録もハンドル変更も要らない。

そのために **商品には必ず最下層のタグ(`pet-bed` 等)を付ける。**
`pet` のような束ねタグを商品に直接付けない。

### 作成・移行の実績(2026-08-23)

**全コレクションを英字タグ条件へ移行済み。** 手順は §4-2 のとおり。

| handle | 条件 | 件数 |
|---|---|---|
| `pet` | `pet-bed` / `pet-furniture` / `cat-tower` / `pet-goods` | 3 |
| `chair-stool` | `chair` / `stool` | 5 |
| `table` | `table` | 4 |
| `storage` | `storage` | 3 |
| `lighting` | `lighting` | 6 |
| `fabric` | `rug` / `cushion` / `bedding` / `textile` / `pajama` | 7 |
| `goods` | `mirror` / `object` / `decor` | 9 |
| `interior` | 上記のうち **ペット以外の全タグ** | 34 |
| `sale` | `sale` | 0 |
| `new-arrivals` | **手動タグ `new-arrival`**(D-041) | 1 |
| `cat-life` | productType=猫用ベッド **または** タグ=猫のくらし(**旧・トップページが使用中**) | 1 |

ペット3 + インテリア34 = **37 で全商品が漏れなく分類されている。**

`cat-life` は旧トップページが接続しているため残してある。`pet` に統合するかは **PENDING**。

### §4-2. 英字タグへの移行手順(D-045・必ずこの順)

一度、商品タグを先に変えてコレクションの接続を切った事故がある。**順序を守ること。**

1. **コレクション条件を新旧併記にする**(日本語タグ **OR** 英字タグ)
2. **商品タグを英字へ移行する**
3. **全コレクションの件数を移行前後で照合する**(減っているものが1つでもあれば止める)
4. **日本語条件を削除する** → もう一度件数を照合する

  日本語ラベルへマップしてから出す
- 「ドロップシッピング」「仕入れ元」等を示すタグを付けない

## §8. 商品命名規則(D-047・2026-08-23 確定)

**新しい商品名を付ける前に必ずこの節を読むこと。** 愛称は使い回しが効かないので、
下の語彙表で重複を確認し、**新しく付けたら必ずこの表に追記する。**

### 3行ルール

```
1. 形式: [愛称(tier-hero / tier-core / tier-brand-builder のみ)] + [素材/モチーフ] + [カテゴリ名]
   ※ tier-aov は説明形のみ(愛称を付けない)
2. 複数色バリアントを持つ商品の商品名に色名を使わない(単色商品のみ可)
3. 愛称はカタカナ2〜3音、形・モチーフ・機能に由来させる(例: ロンド=丸、クラウド=雲)
```

### 使用済みの愛称(重複禁止)

| 愛称 | 由来 | 使用商品 |
|---|---|---|
| モコ | ボア地のふくらみ(推定) | モコ ラウンジチェア |
| クラウド | 雲形の天板 | クラウド サイドテーブル |
| ロンド | 円(rondo) | ロンド コーヒーテーブル |
| ハル | 明るい木肌(推定) | ハル ダイニングチェア |
| ビス | 座面のビス留めディテール(推定) | ビス ダイニングチェア |
| セル | モジュール(cell)構造 | セル サイドボード / セル モジュールキャビネット |
| デュオ | 木×ステンレスの2素材(推定) | デュオ ナイトテーブル |
| ルナ | 円形の月 | ルナ ウォールライト |
| ソラ | 宙に浮くハンモック | ソラ キャットハンモック |
| ピボ | 回転(pivot) | ピボ テーブルランプ |
| ロロ | ローラー(rolling) | ロロ サイドテーブル |
| コイル | スプリング脚 | コイル サイドテーブル |
| ディット | ホームモック内に既出 | (テーマモック) |
| ソリ | ホームモック内に既出 | (テーマモック) |

> 「(推定)」はオーナーから由来の明示がなく、こちらで補ったもの。違っていれば修正すること。
>
> **セル** は同一構造のシリーズなので、2商品での共用は意図的。
> 構造が違う商品に同じ愛称を付けないこと。

### シリーズ

| シリーズ | タグ | 対象商品 |
|---|---|---|
| **フラワー**(MORU 初の公式シリーズ) | `series-flower` | MORU フラワーラウンジ / フラワー キャットタワー / フラワー フロアクッション / フラワーバッド ナイトライト / フラワーバッド テーブルランプ |

シリーズタグは**スマートコレクションの条件には使わない**。広告・特集ページで束ねるための内部タグ。

### 命名時のチェック

- [ ] 多色バリアント商品の名前に色名が入っていないか
- [ ] tier に応じた愛称の有無が合っているか(`tier-aov` は説明形のみ)
- [ ] 愛称が上の表と重複していないか。新規なら表に追記したか
- [ ] 他社の商標・型番(USM / バウハウス / SC53 等)が入っていないか
- [ ] 「中古」(中国語 中古风 = ミッドセンチュリーの誤訳)が残っていないか
- [ ] docs/01 §7 の禁止表現(無垢材 / 完全防水 / 丸洗い可能 / 品質保証 等)が入っていないか
- [ ] **オーナー承認を得てから title を確定したか(勝手に確定しない)**
