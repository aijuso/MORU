---

## §1. ナビカテゴリ(6分類・確定)

```
ペット / チェア・スツール / テーブル / 照明 / ファブリック / 雑貨
```

**設計意図**: 「ペット」を1分類に閉じ込め、残り5分類を通常のインテリア分類にする。
これで **Pet-first, Interior-always.**(ペット専門店に見えない)がナビの形として成立する。

**「ペット」を先頭に置くのは Hero 商品への導線のため。** 分類数の主従は 1:5。

## §4. Shopify コレクション設計

ナビ6分類それぞれに対応するコレクションを作る。**すべてスマートコレクション(タグ条件で自動化)。**

| コレクション | handle | タグ条件(いずれかに一致) |
|---|---|---|
| ペット | `pet` | `pet-bed` / `pet-furniture` / `cat-tower` / `pet-goods` |
| チェア・スツール | `chair-stool` | `chair` / `stool` |
| テーブル | `table` | `table` |
| 照明 | `lighting` | `lighting` |
| ファブリック | `fabric` | `rug` / `cushion` / `bedding` / `textile` / `pajama` |
| 雑貨 | `goods` | `mirror` / `object` / `decor` |
| すべてのインテリア | `interior` | 上記のうち **ペット以外の全タグ** |

### 2層設計にしておく理由

将来「ペット」配下を分割する(`pet-bed` / `cat-tower` 等を独立コレクションにする)ときは、
**タグの束ね直しだけで済む。** 商品の再登録もハンドル変更も要らない。

そのために **商品には必ず最下層のタグ(`pet-bed` 等)を付ける。**
`pet` のような束ねタグを商品に直接付けない。

### 既存コレクションの扱い

前セッションで作成済みの `new-arrivals` / `cat-life` ほかは、
**上表と競合しないなら残す**(`new-arrivals` は「新着」ナビが使う)。
`cat-life` は `pet` に統合できるか要確認 → **PENDING**。

## §5. 内部タグ(命名規則)

**アングル早見表18分類(`docs/brand/reference-sheets/04_category_angles.md`)と1対1で対応させる。**

### カテゴリタグ(商品に必ず1つ以上)

| ナビ分類 | タグ |
|---|---|
| ペット | `pet-bed` / `pet-furniture` / `cat-tower` / `pet-goods` |
| チェア・スツール | `chair` / `stool` |
| テーブル | `table` |
| 照明 | `lighting` |
| ファブリック | `rug` / `cushion` / `bedding` / `textile` / `pajama` |
| 雑貨 | `mirror` / `object` / `decor` |

### 補助タグ(任意・スマートコレクションの条件には使わない)

| 種別 | タグ | 由来 |
|---|---|---|
| スタイル | `new-retro` / `k-pop-color` / `mid-century` | シート04 の 9・10 番 |
| 素材 | `chrome-glass` | シート04 の 8番 |
| 階層 | `tier-hero` / `tier-core` / `tier-brand-builder` / `tier-aov` | docs/00 v0.2 §0-7 |

**`tier-*` タグは必須。** 商品システム4階層のどれかが決まらない商品は登録しない
(Value ⑤ Curated, Not General Store)。

### タグの禁止事項

- **顧客に見える形でタグを出さない**(内部管理用)。カテゴリページの絞り込みUIに出す場合は
  日本語ラベルへマップしてから出す
- 「ドロップシッピング」「仕入れ元」等を示すタグを付けない
