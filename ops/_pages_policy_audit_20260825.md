## 7. 返品条件 — Frontend の「30日返品」を決めるための事実

**Owner に決めていただくための材料。こちらでは決めていない。**

### 現在ストアに存在する事実

| 場所 | 書いてある内容 |
|---|---|
| 特商法ページ(未公開) | **到着後7日以内**・**不良品または誤配送のみ**・交換または返金 |
| FAQ(未公開) | **到着後7日以内**・**不良品または誤配送のみ**・交換または返金 |
| PDP アコーディオン(公開されるテーマ側) | **到着後7日以内**・不良/誤配送のみ。お客様都合のキャンセルは原則不可 |
| **Shopify の返金ポリシー** | 🔴 **存在しない** |
| ホーム USP(DEV) | 「**30日間の返品・交換**」「届いてから、ゆっくり決められます」 |
| PDP 信頼バッジ(DEV) | 「**30日返品対応**」「イメージ違いでも安心の30日返品保証」 |
| カートページ(DEV) | 「**30日返品対応**」 |

### 矛盾の中身

**「30日返品」「イメージ違いでも安心」は “お客様都合の返品を30日受ける” と読める。**
一方、ストアの文書側は **“不良・誤配送のみ・7日以内”** で、**お客様都合の返品は受けないと書いてある。**
**同じサイトの中で正反対のことを言っている。**

### 決めていただきたいこと

**A. 実態を「7日・不良/誤配送のみ」にする場合**
→ USP・信頼バッジ・カートの「30日返品」表示を**削除または書き換え**(Frontend = ChatGPT)
→ Shopify に**返金ポリシーを作成**して、その内容を書く

**B. 実際に「30日・お客様都合可」を運用する場合**
→ 特商法ページ・FAQ・PDP アコーディオンを**全て書き換え**
→ 返送料の負担者・返品条件(未使用/開封済み)・海外取り寄せ品の扱いを決める
→ Shopify に**返金ポリシーを作成**
→ **海外取り寄せモデルで30日のお客様都合返品を受けると、返品コストが原価計算に効く。**
  `docs/10 §4` の返品コストは現在 **0(未確認)** で置いてあるので、**採算の前提が変わる**

> **どちらを採るかは Owner の事業判断。**こちらで文面は作らない。
