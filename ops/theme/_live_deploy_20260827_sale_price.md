## ハマったこと

- **ストアフロントを連続で叩くと 503 を返す。** 28件を 400ms 間隔で回したら5件が 503 になった。
  `/cart/add.js` の 429 とは別で、PDP の GET でも起きる。
  **503 は「非セール」ではなく「取得できなかった」** なので、
  ステータスを見ずに本文だけ判定すると**取りこぼしを PASS と誤報告する。**
  3秒からの指数バックオフで再取得して全件 200 を取った
- セール時の class は `moru-product__price` を**置き換えではなく追記**する
  (`class="moru-product__price moru-product__price--sale"`)。
  `class="moru-product__price--sale"` で引っかけようとすると全件ハズレる
