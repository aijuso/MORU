# ops/ads/benchmarks — 競合広告の分析(分析の作法)

競合の広告を分析するときは、まずこの作法に従う。個別の分析は各ファイルへ。

| ファイル | 対象 |
|---|---|
| `kocol.md` | kocol.shop(完成された勝ちパターン。特集型) |
| `desk-nest-cat-bed.md` | Desk Nest Cat Bed(探索中の若い広告主。問題提起型) |

**広告制作の着手前に本書を読むこと(CLAUDE.md 絶対ルール16)。**

## 指標の読み方

- 信頼できる勝ち指標は**稼働日数**。
  performance score は全広告同一の既定値なので**使わない**
- 推定出稿額は幅が広く、**桁感の参考程度**
- **ツールのフック分類ラベルを鵜呑みにしない。**
  必ずコピー本文を自分で読んで真のフックを判定する
  (実例: Kocol は5本が problem_agitation と分類されたが、実際は1本だけだった)

## 借りる / 捨てる

| 借りる | 捨てる |
|---|---|
| 構図 | 競合のトーン(高彩度・煽り・大きな文字焼き込み) |
| フックの型 | 期限付き割引訴求("Presale ends soon" 等。MORUは使わない) |
| 訴求の順序 | |
| 特集で束ねる構造 | |
| 静止画主体という判断 | |

「捨てる」の根拠は CLAUDE.md 絶対ルール6(偽の希少性・偽カウントダウンの禁止)と
docs/01 §4(表示が事実かの一点で判定)。
