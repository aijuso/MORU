# kocol.shop の広告分析

- **44本同時稼働 / 最長125日 / 推定出稿額 $241k〜$448k。**
  完成された勝ちパターンを持つ
- **勝ち型は「特集」**: 「テーブル・椅子特集」「カラフル収納特集」「夏パジャマ特集」等、
  単品ではなくテーマで複数商品を束ねる型が4ヶ月稼働
- フォーマットは **slideshow / studio_product が主力**。UGC動画はほぼ使わない
- **割引訴求をほぼ使っていない。** 値引きなしで4ヶ月回せている
  → **MORUの「偽の希少性・二重価格を使わない」方針は不利にならないことの実証**
- 本物の問題提起型は**1本だけ**(「寝苦しい夜とは、もうサヨナラ。」夏パジャマ・125日稼働)
- 広告の着地先はコレクションではなく `/blogs/features/〇〇` の**特集記事ページ**

## 重要な経済的理由 — 特集型はAOVを上げる装置

特集型は単なるクリエイティブの型ではない。

安い商品(限界利益¥1,100前後、CPA上限¥800)は**単品広告では成立しない**が、
特集で複数点購入させれば **AOV¥8,000〜10,000** に乗る。

→ リサーチの「セット候補」列(`ops/research/rubric.md`)が
そのまま特集広告の企画になるのは、この構造のため。
