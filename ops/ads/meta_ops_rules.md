# Meta広告 運用ルール(2026-08-31 制定)

> 出典: オーナーコンサル資料 ステップ15(`docs/consulting/playbook_digest_20260831.md`)を
> MORU の実測値・既存ルールと突き合わせて明文化したもの。
> **CPA上限や判断保留ラインなど数値の正は `_ad_link_rules.md` と `ops/products/_price_audit_20260829.md`。**
> 本書は「いつ・何を・どの頻度で触るか」の運用ルールのみを扱う。

## 学習期間(配信開始〜7日)

- **配信開始から3〜7日は予算・ターゲットを大きく変更しない。** 学習の安定を優先する
- クリエイティブの勝ち負け判断は**表示回数が付いてから**。
  imp が数件しか無いものは「負けた」ではなく「データなし」(2026-08-29 実測:
  画像2本が 3imp / 5imp で未学習だった)
- ページ改修・CPA判断は **LPV累計500まで保留**(`_ad_link_rules.md` の既定)

## 週次

- **クリエイティブの入れ替え**: フリークエンシー上昇 → CTR低下(疲弊)を防ぐ。
  1商品につき動画・静止画あわせて**3〜5パターンを維持**し、パフォーマンス下位から差し替える
- 新パターンは `.claude/skills/ad-benchmark-creative/` のワークフローで作る
  (競合分析 → 要素分解(フック/問題提起/解決策/証拠/CTA) → MORU 翻訳)

## 日次

- **CPA / CTR / ROAS を確認**し、`_ad_link_rules.md` の観測メモに追記する(日付必須)
- CPA上限(現行の正: **¥3,267**。`_price_audit_20260829.md`)を超えた日は記録する。
  ただし **n が小さいうちは行動しない**(初日 n=1 で ¥359 超過 → 行動不要と判断した前例)

## 不変ルール

- クリエイティブが特定色を見せているなら、リンク先は**その色の `?variant=` 付きURL**(`_ad_link_rules.md`)
- Meta広告ポリシー(誇大表現・ビフォーアフター制限)と CLAUDE.md ルール5・6
  (配送目安の明示 / 偽レビュー・偽割引・偽カウントダウン禁止)は広告文言にも適用する
- 学習リセットを避けるため、既存広告セットの編集より**新規追加**を優先する
