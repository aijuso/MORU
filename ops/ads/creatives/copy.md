# 見出し・本文の設計

## Meta動的クリエイティブ(見出し5・本文5・説明5)の設計原則

- **5つを同じことの言い換えにしない。角度を変える**
  (逆張り / インテリア問題 / 共生 / 機能 / 商品そのもの)。
  同じ角度で5本作ると、当たっても何が効いたか分からない
- 組み合わせはランダムに入れ替わるため、**それぞれ単独で成立**するように書く
- 本文は冒頭125字ほどで折りたたまれるので、**1行目に結論を置く**
- 説明(Description)は Instagram では表示されないことが多い。
  重要情報を入れず、空欄にもせず、**事実の補足**を置く

## 書いてはいけないこと

| 表現 | 理由 |
|---|---|
| 送料無料 | しきい値が未確定(表示¥15,000 / 設定¥7,700 の不整合が未解決) |
| 配送の速さ | 実態は2〜3週間(CLAUDE.md 絶対ルール5) |
| 「累計○個販売」「人気No.1」等の実績 | まだ無いため虚偽になる(絶対ルール6・7) |
| 価格 | sale タグ運用中のため広告文と実価格がズレるリスク |
