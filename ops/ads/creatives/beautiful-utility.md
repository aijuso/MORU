# Beautiful Utility — 機能をインテリアの言葉に翻訳する型

Values①「Beautiful Utility」の書き方。**買う人と使う人が違う**ため、
ペットのための機能を**飼い主のための価値に翻訳する**。

## 翻訳の例

| 機能(事実) | 翻訳(飼い主のための価値) |
|---|---|
| 床から約11cm浮かせる | 機能は「ほこりと冷たさから離す」だが、同時に「脚の下に床が続いて見えるぶん、同じ大きさの箱型より軽く感じられる」 |
| 通気性のある生地 | 「乾きやすい = 洗って戻せる = 生活感が出ない」 |
| 花びらの形 | 「猫が沈む = だらしなく見えない、置いてあるだけで景色になる」 |

## 表現の制限

- **「部屋が広くなる」は不可**(事実として広くならない)。
  「広く見える」「軽く感じられる」「重くならない」など、
  **見え方・感じ方の表現に留める**
- **数値は実測値のみ。** 未確認なら「約」を付けるか、サンプル実測まで書かない
  (CLAUDE.md 絶対ルール8・15)

## 既存の商品説明が手本

MORU の商品説明は既にこの話法で書かれている:

- セル サイドボード:「床が連続して見え、実際の寸法より軽く感じられます」
- ロロ:「側面が開いているので同じ寸法の箱型より部屋が狭く見えません」

**新規商品の説明文もこれに揃えること。**
