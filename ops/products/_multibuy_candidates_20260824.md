## 商品ごとの推奨理由と注意事項

### 1. 手編みコースター(¥3,480–3,980 / 7 Variant)
**理由:** コースターは**4枚1組で使うのが標準**。1枚だけ買う理由がほぼ無い。全36商品で最も自然。
Variant がアヒル / カエル / リス / カメ / トカゲ / マウスと**全部違う生き物**なので、
「別 Variant を混ぜて3点」という Function の挙動がそのまま買い方に一致する。
**注意:** ⚠️ **`review-required` タグが付いたまま。** ブランド適合の判断が先。
原価 ¥88 は18→7に整理する前の値で、残った7 Variant のどれの値か不明(**原価待ち**)。

### 2. セラミック ブックエンド(¥7,980–8,480 / 4 Variant)
**理由:** ブックエンドは**本の両端に置く=2個で1機能**。「2点10%」の説明がいらない唯一の商品。
**注意:** 3点以上は主流ではないので、実質「2点10%」だけが効く。
Variant 価格が2種(¥7,980 / ¥8,480)あるため**原価も2種必要**(原価待ち)。

### 3. ルナ ウォールライト(¥9,480–9,980 / 8 Variant)
**理由:** 廊下・階段・ベッド左右のように**同じ灯を複数箇所に付ける**のが前提の照明。
**注意:** ⚠️ **現在 DRAFT。** 公開が先。光色2種で価格が違う(¥9,480 / ¥9,980)ので原価も2種(原価待ち)。
単価が1万円弱なので、3点15%OFF は割引額 ¥4,300 前後になる。ここは Owner 判断がほしい。

### 4. フラワーバッド テーブルランプ(¥6,980 / 4 Variant)
**理由:** ベッドサイド左右で2灯、色違いで揃える動機がある。`series-flower` の一員で、
シリーズを揃える動線とも噛み合う。
**注意:** 原価 ¥470 は「参考可(単一価格)」で ×3.14。**13商品の中で原価の確度が最も高い1つ。**
3点以上は主流ではない。

### 5. フェイクファー ブランケット(¥3,480–4,480 / 30 Variant)
**理由:** 色10×サイズ3。**家族分・部屋ごとに複数枚**が自然で、単価も2〜3枚のカゴに合う。
**注意:** サイズ3種で価格が2段(¥3,480 / ¥4,480)。**サイズ別の原価が必要**(原価待ち)。
記録原価 ¥200 は最小サイズの値と見られる。

### 6. フランネル ブランケット(¥3,480–4,480 / 33 Variant)
**理由:** 同上。色11×サイズ3。
**注意:** 同上(原価待ち)。**5番と2商品並んでいるので、片方だけ対象にすると不自然。
2つセットで判断してほしい。**

### 7. ベルベット クッション(¥5,480–7,980 / 8 Variant)
**理由:** ソファには**2〜3個並べる**のが普通。柄8種で組み合わせが成立する。
**注意:** ⚠️ **柄によって価格が4段(¥5,480 / 5,980 / 6,980 / 7,980)。**
Function は率で掛けるので割引額は柄ごとに変わる。それ自体は正しい挙動だが、
**フロントの「想定10%/15%」表示が最小価格だけを見ていると実額とズレる。**
記録原価 ¥570 は廃止した「カバーのみ」の値(原価待ち)。

### 8. パイピング クッション(¥5,980–6,980 / 8 Variant)
**理由:** 同上。
**注意:** 価格3段。記録原価 ¥570 は「カバーのみ」の値(原価待ち)。

### 9. ジャカード 中綿付きクッション(¥3,980 / 5 Variant)
**理由:** クッション3種の中で**最も気軽な価格**。2〜3個買いの入口として最適。
**注意:** 全 Variant 同一価格なので Function の挙動が最も素直。
記録原価 ¥238 は「カバーのみ」の値(原価待ち)。

### 10. フラワー フロアクッション(¥7,480–8,480 / 8 Variant)
**理由:** 色4×サイズ2。子ども用・来客用に複数枚。`series-flower` の一員。
**注意:** 🚩 **13商品の中で唯一、原価が説明できない**(記録 ¥595 に対して ×6.08。
Variant を1つも削っていないのに倍率が跳ねている)。**原価が判明するまで対象にしないほうがよい。**

### 11. バルーンドッグ オブジェ(¥3,980 / 9 Variant)
**理由:** 9色。**色違いを並べて飾る**のが商品の使い方そのもの。3点以上が最も起きやすい。
**注意:** `tier-brand-builder`。ブランドの見せ札を割引対象にしてよいかは Owner 判断。
原価 ¥475 は「参考可」で ×3.12。

### 12. ガラスフラワー オブジェ(¥3,980 / 5 Variant)
**理由:** 5色の7点セット。**色を足して束を大きくする**動線がある。
**注意:** 記録原価 ¥70 は削除した「単品1本」の値。**現行は全て7点セット**なので
¥70×7 ≒ ¥490 なら ×3.09 で式どおりになる(**推定であって確定ではない。原価待ち**)。

### 13. ミニ アラームクロック(¥4,980 / 4 Variant)
**理由:** 4色。子ども部屋+寝室のように**部屋ごとに置く**。
**注意:** 3点以上は主流ではない。原価 ¥719 は「参考可」で ×3.28。
