# 商品説明 → 特徴(custom.features)への統合(2026-08-28)

> 指示: docs/06_handoff.md §7.8(Owner)。商品ページから「商品説明」アコーディオンを撤去した
> (D-161 追記7)ため、`product.description` はページのどこにも表示されていない。
> 説明文にしかない情報を、特徴メタフィールドの記事組み(D-154: 見出し → 画像 → 説明文)へ移す。

## 方針(この作業で使った判断基準)

1. **「情報が失われていないか」で判断する。** 説明文の一文ごとに、それが
   特徴(`custom.features`)・仕様表(`custom.specs`)・カラースウォッチ(`custom.swatch_colors`)・
   キャッチコピー(`custom.catch_copy`)・「配送について」のどこかに残っているかを見た
2. **仕様表に載っている数値・素材・確認中項目は移さない。** 「素材・サイズ」アコーディオンに
   出ているので失われていない。ただし**特徴の本文に置いたほうが読まれる寸法**(全体サイズ・
   本数・セット内容)は特徴側にも書いた
3. **カラーの列挙は移さない。** バリアントのカラースウォッチと仕様表に出ている
4. **配送目安の段落は移さない。** 「配送について」アコーディオンに集約済み(D-161 追記7)
5. **どこにも残らない文だけを移す。** 具体的には ①問題提起の入り(その商品が何のためにあるか)
   ②飼い主価値への翻訳(beautiful-utility.md の型)③注意喚起 ④特徴にない機能・寸法
6. **新しい特徴ブロックは作らない。** 画像とセットで成立する組み(D-154)なので、
   画像のない行を増やさず、既存ブロックの本文に織り込んだ
7. 表現は CLAUDE.md 絶対ルール8・15(未確認の品質表現をしない)に従う。
   説明文にあっても**裏付けのない一文は移さずに落とした**(下の「落とした表現」)
