# 確認できなかったもの — オーナー報告用(随時追記)

作成: 2026-08-24 / 最終更新: 2026-08-24

商品説明・メタフィールドを登録する過程で、**Shopify に登録済みの商品画像から読み取れなかった項目**を
ここに積んでいく。商品ページ側には「確認中」と表示し、判明し次第そのページを更新する。

判断ルール(CLAUDE.md 絶対ルール15):
- 画像に書いてあることは書いてよい。**書いていないことは書かない。**
- 取れなかったものは仕様表に「確認中」と書き、この表に積む。

| 商品 | 確認できなかった項目 | 状況 |
|---|---|---|
| クラウド サイドテーブル | 寸法すべて | 登録画像20枚に寸法図が1枚もない |
| デュオ ナイトテーブル | 寸法すべて | 同上 |
| ロンド コーヒーテーブル | 天板・脚の素材 | 寸法図には「胡桃木色(ウォールナット色)」とあるだけで樹種・芯材の記載なし。**無垢材とは書けない** |
| モコ ラウンジチェア | 脚の素材 | 寸法図で5本脚・回転式と確認。金属光沢だが材質表記なし |
| ハル ダイニングチェア | (寸法は取得済み) | 木部は仕入れ元表記「アッシュ材」。実物確認は未 |
| ビス ダイニングチェア | 木部の樹種 | 「実木」表記のみで樹種の記載なし |
| ボア ラウンジチェア | 幅・奥行 | 寸法図に2サイズ(幅67×奥行55 / 幅73×奥行60)の記載。**当店が仕入れるのがどちらか不明**。総高67cm・座面高42cmは両サイズ共通なので記載済み |
| ボア ラウンジチェア | 脚の素材 | 記載なし |
| セル モジュールキャビネット | 素材すべて | 説明画像が1枚もない(ギャラリー5枚のみ)。寸法はバリアント名から取得 |

## 寸法以外で報告が必要なもの

- **セル モジュールキャビネット**: 登録済み商品画像5枚すべてに**仕入れ元(义乌市…家具行)の透かしが入っている**。
  画像は削除しない方針のため未対応。差し替え用の画像が必要。なおこの商品は現在 DRAFT。
- **ロンド コーヒーテーブル**: 仕入れ元の説明画像に「1年质保(1年品質保証)」「破损补寄」等の
  アフターサービス表記がある。**当店では履行できないため説明文には一切引用していない**。
- **ボア ラウンジチェア**: 仕入れ元の説明画像に返品・違約金・倉庫保管料など**中国国内向けの取引条件**が
  そのまま入っている。日本の顧客向けには成立しないので引用していない。
