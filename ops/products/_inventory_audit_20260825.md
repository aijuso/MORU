前回 `product.totalInventory` が 0 と返るのを見て「在庫0で公開できない」と報告した。**これは誤読。**

Shopify は追跡していない商品を**常に購入可能**として扱う。

実測:

| 指標 | 値 |
|---|---|
| `availableForSale = true` | **257 / 257(全件)** |

| `tracked = true` | **2**(MORU フラワーラウンジのみ・各5点) |
| `inventoryPolicy` | **全件 DENY** |
| `requiresShipping` | **全件 true** |
| Location | **Shop location 1箇所のみ**(`isActive: true` / `fulfillsOnlineOrders: true`) |

**つまり在庫はローンチ阻害ではない。**この項目は BLOCKER から取り下げる。

## CKB 連携上の想定と、そこから出てくる論点

### 1. `inventory_quantity` に仕入れ元の在庫数がそのまま入っている

追跡していない(`tracked = false`)ので**販売判定には一切使われない**が、数字自体は残っている。
値は明らかに CKB 側の在庫をそのまま取り込んだもので、桁が現実的でない:

| 商品 | 数量 |
|---|---|
| プラッシュ クッション(DRAFT) | **773,835 / 765,323 / 760,168 / 713,137 / 545,695** |
| クラウド サイドテーブル | 100,244 / 100,387 / 100,415 |
| フラワーバッド テーブルランプ | 15,656 – 21,872 |
| フェイクファー ブランケット | 7,845 – 9,985 |

一方で **0 が入っている Variant が2件**ある(どちらも購入可能なまま):

| 商品 | Variant ID | 数量 |
|---|---|---|
| マッシュルーム コードレステーブルランプ | `.../50296081383664` | **0** |
| フラワー フロアクッション | `.../50296389042416`, `.../50296389173488` | **0** |

**これは「CKB 側で在庫が切れている可能性がある Variant」を示している。**
在庫を追跡していないので Shopify は普通に売ってしまう。**発注できるか確認が要る。**

### 2. PDP の在庫表示は壊れない(実装を確認した)

`sections/moru-main-product.liquid`(**DEV と MAIN で checksum 完全一致**・ローカルとも一致)は

```liquid
if current_variant.inventory_management != blank
  assign tracked_quantity = current_variant.inventory_quantity
endif
```

と**追跡していない商品では数量を読まない**作りになっている。
`stock_display: "inventory"` のとき在庫ラベルは `tracked_quantity > 0` のときだけ出るので、
**追跡なしの商品では在庫メッセージが何も出ない。**「残り773,835点」のような表示にはならない。

> ⚠️ ただし同ファイル 316行目で、全 Variant の `inventory_quantity` を JSON として
> **ページの HTML に埋め込んでいる**。Liquid が追跡なし Variant に対して 0 を返すのか
> 生の数値を返すのかは、**実機で HTML を見て確認したほうがよい**(表示ロジックには影響しない)。
> 確認は Frontend 側(ChatGPT)の担当範囲。

### 3. `DENY` は現状ほとんど意味を持たない

`inventoryPolicy = DENY`(在庫切れで販売停止)が全件に付いているが、
**追跡していないので在庫切れという状態にならない。**
将来 CKB 在庫を Shopify に同期する運用へ変えるなら、この設定が初めて効き始める。

### 4. MORU フラワーラウンジだけ運用が違う

唯一 `tracked = true` で在庫10点(5+5)。**10点売れたら DENY で売り切れになる。**
他の35商品と運用が揃っていない。**意図的かどうか確認したい。**

### 5. 配送設定から出てきた別の論点

| # | 内容 | 深刻度 |
|---|---|---|
| 5-1 | **国際配送ゾーンが有効。**条件は「総重量 0〜2kg で ¥3,000」。一方 **全商品の重量が 0kg**(セル サイドボード・デュオ ナイトテーブルで実測確認)。つまり **¥92,480 のキャビネットでも国際送料 ¥3,000 で注文が通る** | 🔴 **BLOCKER** |
| 5-2 | 国内配送に「**速達 ¥3,762**」がある(条件なし)。実際の納期は**海外取り寄せで2〜3週間**。速達に見合う実態が無い | 🔴 **BLOCKER**(CLAUDE.md 絶対ルール5) |
