> 原則想定は「1商品 = カラー違いのみ」。それ以外の軸(サイズ / セット構成 / 仕様 / ギフト箱)を
> 持つ商品を全件並べた。**オプション名・値は仕入れ元の原文のまま**(機械翻訳の崩れも含む)。

## 全体の推奨(まとめ)

| 対応 | 対象 | 効果 |
|---|---|---|
| **受注生産・管理用の値を外す** | モジュールキャビネットのカスタマイズ3 / フレンチチェアのカスタマイズ1 / ブックエンドの2値 / ボアの「デラックスプラスカラー備考」2 | **注文が入っても対応できない値を消す。最優先** |
| ギフトボックス値を外す | フラワーバッド2種 / マッシュルーム | 単品と混ざって価格が飛ぶ |
| セット構成を Shopify の割引機能へ移す | コーヒーテーブルのコンビ12 / ダイニングチェアの4脚パック | バリアントが減り、割引の管理も楽になる |
| 柄・色を絞る | クッション2種(31柄・22柄)/ ブランケット2種 | サムネを全柄分用意するのは非現実的 |
| 商品の統合・分割 | アートオブジェ(分割)/ フラワーバッド2種(統合)/ ブランケット2種(統合) | 何を売る商品か1秒で分かるように |

**現在の合計バリアント数は約600。上記をすべて適用すると 150〜200 程度になる見込みです。**
