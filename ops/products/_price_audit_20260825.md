## ⚠️ 着地原価は「実測」ではなく「推定」です

今回取得したのは **`ckb_cost` = CKB 画面の商品原価(JPY)だけ**。
国内送料・代行手数料・国際送料・関税の実測値は**まだ1件も無い**。

```
landed_est = ckb_cost + ship_est
```

**`ship_est` は実送料ではありません。**台帳の既存列にある**価格設計用の送料概算**で、
小物 ¥800 / 中型 ¥1,750 / 大型 ¥3,500 の3段です。

- **`_ckb_costs.csv` の `ckb_cost` は CKB の商品原価そのままで保存**しています。
  送料概算を足して上書きしていません。`landed_est` は監査ツール側で毎回生成します
- **実測 landed が入れば、そちらが優先されます**(下記の採用順)。今は実測 0 件
- **`ship_est` の精度がそのまま判定の精度**です。特に **ship_est の比率が高い低単価商品**
  (ブランケット ¥324 の原価に ¥800 の送料概算 = 原価の71%が送料概算)は、
  **実送料が判明したら判定が変わりうる**ことを承知の上で読んでください

## 4. 🔴 いちばん重要な発見 — **docs/10 の ×3.0 と docs/12 の「15%OFF後 ×2.6」は両立しない**

```
×3.00 × 0.85 = ×2.55  < 2.6   ← docs/12 のスクリーニングを必ず割る
```

**「着地原価 ×3.0 で値付けする」というルールどおりに作った商品は、
15%OFF を出した瞬間に必ず基準を割ります。**これは個別商品の問題ではなく**ルール同士の矛盾**です。

必要な通常倍率:

| 割引 | 15%OFF 後に ×2.6 を保つのに必要な通常倍率 |
|---|---|
| **15%OFF** | **×3.06 以上** |
| **10%OFF** | **×2.89 以上** |
| 0%(通常) | ×2.60 以上 |

これが「🟡 要検討 13商品」の正体です。**13商品すべてが ×3.02〜3.06 に張り付いている**だけで、
赤字でも異常でもありません(粗利率はいずれも 61% 台)。

### 対処案(Owner 判断)

|---|---|---|

### 5-2. 🟢 値下げ余地はあるが、**据え置きを推奨** — 3商品

| 商品 | 現価格 | 現倍率 | ×3.0 の機械案 | 推奨 |
|---|---|---|---|---|
| フラワー フロアクッション | ¥7,480–8,480 | ×5.01–5.37 | ¥4,480–5,480 | **据え置き** |
| ボア ラウンジチェア | ¥16,480 | ×4.55 | ¥10,980 | **据え置き** |
| モコ ラウンジチェア | ¥42,480 | ×3.48 | ¥36,980 | **据え置き** |

**理由:**

1. **`×3.0` は下限であって目標値ではありません。**上振れしている商品を機械的に下げると、
   粗利を捨てるだけになります
2. **注文が0件なので、値下げが必要かどうかを判断する売れ行きデータがありません。**
   下げるなら「高くて売れない」という事実が先に要ります
3. **`landed` は推定です。**`ship_est` が実態より低ければ倍率は過大に見えます。
   ボア(¥1,871 + 中型 ¥1,750)のように **送料概算が原価の半分近い商品**では、
   実送料が判明した時点で倍率が大きく動きます。**推定値で 33% の値下げを決めるのは危険です**
4. フラワー フロアクッションは前回「原価が説明できない ×6.08」として最優先で実測を求めていた商品です。
   CKB原価が入って **×5.0台**に落ち着きました。**異常値ではなくなりました**が、
   **同じクッション帯(ジャカード ×3.35 / ベルベット ×3.04–3.23 / パイピング ×3.16–3.22)から見ると
   突出して高い**のは事実です。競合価格との比較が要ります(原価だけでは決められません)

**値下げは「価格が高すぎて売れない」という根拠が出てからで間に合います。**
