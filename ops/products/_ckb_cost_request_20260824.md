# CKB 原価の取得依頼(Owner 向け・2026-08-24)

> **なぜ Claude 側で取れないのか。**
> Shopify には原価が1件も入っていない(`inventoryItem.unitCost` は全257 Variant で `null`、
> Variant metafield は0件、重量も全件 0kg)。取り込み直後は「価格欄 = CKB 仕入れ値」だったが、
> **その後の値付けで全 Variant の price が上書きされ、Admin API に価格履歴は無い。**
> `www.ckb.jp` へは実行環境から到達できず、認証情報も無い。
> → **CKB の管理画面を開ける Owner にしか埋められない。**

## 埋めかた

- **1行 = 1 Variant。** 商品あたり1値ではなく、**Variant ごと**にお願いします
- 分からない項目は **空欄ではなく「未確認」** と書いてください(推測値を入れない)
- **中国国内送料 / 代行・検品等 / 国際送料 / 関税・輸入消費税等が CKB 上で分解できず、
  「合計いくら」しか出てこない場合は、その合計を「着地原価」に書き、他は「未確認」**で構いません。
  分解できないこと自体が記録として価値があります
- 通貨は **JPY**。CKB が CNY 表示なら、**そのままの数値 + 通貨** で構いません(レートはこちらで確認します)
- **優先度1(11商品・62 Variant)だけでも監査は大きく前進します。** 全部まとめて待つ必要はありません
