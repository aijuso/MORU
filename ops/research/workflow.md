# リサーチ実行手順

前提: `README.md`(セットアップ・シート構成)と `rubric.md`(評価基準)を読んでいること。

1. `sites.md` から**タイプA**サイトを選ぶ
2. `/products.json?limit=250` で全商品取得(ページネーションあり)
3. 登録日順に並べ、**新着 = 競合が今賭けている商材**を優先的に見る
4. **在庫切れ(Sold Out)は最強のシグナル。**
   広告データは「宣伝しているもの」しか示さないが、完売は「実際に売れた」証拠。
   **全色 Sold Out は最優先で照合する**
5. `rubric.md` の基準で全商品を評価(**絞り込まず、全件にスコアを付ける**)
6. 日付タブ(`YYYY-MM-DD`)に追記 → `マスターDB` に**商品URLで重複排除**しながらマージ
   (書き込みは `append_rows` + `value_input_option="USER_ENTERED"`。README 参照)
7. 人が判断 → 1688画像検索で照合(**この工程は自動化不可。手作業**)→ CKBで原価見積
8. **日本展開可否チェック**(下記)を通す。1つでも赤なら不採用または専門家確認に回す
9. 採用分を商品登録スキル(`.claude/skills/product-registration/`)へ渡す

## 日本展開可否チェック(商品を採用する前に必ず通す)

> 出典: オーナーコンサル資料 ステップ3(`docs/consulting/playbook_digest_20260831.md` §2)。
> Claude の判断は一次スクリーニング。**最終判断は専門家(弁護士・税理士・通関業者)へ。**

- [ ] **法規制**: 電気製品(電安法/PSE)・電池・磁石・化粧品・健康食品・食品接触(食品衛生法)・
      医療的効能をうたうもの(薬機法)に該当しないか。該当したら原則見送り
- [ ] **知的財産**: 海外オリジナルに見えても意匠権・商標権を侵害する模倣品でないか
      (1688照合時にブランド刻印・キャラクター類似を確認)
- [ ] **配送・関税**: サイズ・重量が送料区分(docs/10)に収まるか。リチウム電池等の輸送制限がないか
- [ ] **季節性・文化的受容性**: 日本の住環境(部屋のサイズ・畳/フローリング)と季節に合うか
