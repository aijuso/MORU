# 通知メールの運用メモ(2026-08-29)

> 通知メールの文面は **管理画面 → 設定 → 通知** で編集する(テーマファイルではない。
> Admin API からは読み書きできないので、変更は Owner の手作業。ここに正を残す)。

## 注文確認メール(2026-08-29 変更)

Shopify 標準テンプレートには**納期の記載が無い**。海外取り寄せ(2〜3週間)の店では
「支払い後、納期不明のまま沈黙」になり、チャージバックと不安問い合わせの温床になる。

### 挿入箇所

`<p>{{ email_body }}</p>`(テンプレート内に1箇所)の**直後**に以下を挿入:

```html
<p>
  <b>お届けまでの目安について</b><br>
  MORUの商品は、ご注文をいただいてから海外の提携先で一点ずつお手配しています。
  お届けの目安は<b>ご注文から2〜3週間前後</b>です。
  在庫状況・国際輸送・通関・天候などの状況により、4週間以上かかる場合があります。
</p>
<p>
  商品を発送しましたら、追跡番号をメールでお知らせします。
  ご注文のキャンセル・変更をご希望の場合は、手配開始後はお受けできない場合がありますので、お早めにこのメールへご返信ください。
</p>
```

- 文面は PDP「配送について」/ FAQ と同一表現に揃えてある(食い違い禁止)
- ⚠️ 「追跡番号をメールでお知らせします」は、**CKB の追跡番号を Shopify に手入力して
  発送処理する運用が前提。** この運用をやめるならこの一文も外す
- `{% capture email_body %}` の分岐の中には入れない(崩れやすい)。分岐の外の1箇所挿入

### ついでに直した標準テンプレートのバグ

- `{{ customer.last_name }}様 様、` → 様を1つ削除(発送時請求の分岐)
- `{{ customer.last_name }}様様、` → 同上(ローカルデリバリーの分岐)
- どちらも現運用(前払い・通常配送)では発火しないが、二重敬称なので修正

### 確認事項

- フッター「このメールにご返信いただくか {{ shop.email }} まで」の返信先 =
  ストアのメールアドレス(設定 → ストアの詳細)。**キャンセル依頼がここに来る。**
  普段見る受信箱であることを確認する

## 発送処理の前提(2026-08-29 の実測)

- CKB はフルフィルメントサービスとして**未接続**(ロケーションは Shop location のみ、
  requestStatus=UNSUBMITTED)。**追跡番号は自動では Shopify に入らない**
- CKB で追跡番号が出たら: 管理画面 → 注文 → アイテムをフルフィルメント →
  追跡番号を入力 → 「発送を通知」で発送完了メールが飛ぶ。**これをやらないと
  お客様は追跡番号を永久に受け取れない**
